## 一致性备份、恢复与删除对账

`milai-ops backup` 要求 API/Steward/Worker quiescent 且数据库为单 tenant。工具在
`REPEATABLE READ` transaction 中锁表、导出 snapshot、执行 `pg_dump --snapshot`、复制 Blob，
并记录 dump、每个 Blob、Alembic revision、全表 inventory 与 consistency fingerprint。

Inventory 不再是手写子集：工具从 catalog 枚举所有含 `tenant_id` 的 durable base table，并要求
与配置集合完全相等；新增 tenant-owned 表却没有进入 inventory 时，备份和恢复都会拒绝执行。
当前集合覆盖 canonical/security、Chat/Context、Episode/Settlement、outbox/delivery/watermark、
search/trace、operational/deletion、backup obligation 与 idempotency 等全部 29 张 tenant 表。
单 tenant 校验也逐表执行。

真实 drill 覆盖以下闭环：

```text
source 0013 + grounded Claim + FTS/vector projection + Episode/Settlement
→ backup A（含 live Blob）
→ TX-05 revoke + purge worker + primary Blob ERASED
→ backup A 产生 PENDING deletion obligation
→ backup B（不含已撤销 Blob）
→ expire backup A
→ obligation 与 deletion.backup_expiry_status COMPLETED
→ pg_restore backup B 到新空数据库与空 blob root
→ 每张 inventory 表 count/hash、canonical IDs、Episode/Settlement、block/watermark 对账 PASS
→ tampered database.dump 被 SHA-256 校验拒绝
```

该证据同时闭合 DG-06 的 `backup/deletion reconciliation`；恢复不覆盖活动实例。

## 故障、repair 与隐私证据

- DB unavailable：readiness、required retrieval、Chat 和 system state 接口返回 503/abstain；
- vector/embedding unavailable：L0/FTS 可降级，vector delivery 可 dead-letter/retry；
- Blob unavailable：正文、pointer recovery 和 purge 明确失败，GroundingBlock 继续 fail closed；
- worker crash/lease/dead-letter：contiguous watermark 不跨 gap，Steward 显式 retry；
- projection rebuild：只清 derived state；outbox replay 恢复最新 sequence，canonical ID/版本不变；
- migration 在新空数据库执行 `base → head → base → head`，当前 head 为
  `0013_live_confirmation_gate`；
- JSON/text log formatter 不插值 message args 或 exception message，request ID 只保留短
  fingerprint；RetrievalTrace/ChatTurn 不保存 query 明文；
- live confirmation 不是字符串开关：action-sensitive Chat 必须引用新鲜、可读、未撤销且字段
  匹配的 `USER_CONFIRMATION` Evidence，数据库写入 procedure 再次校验。
