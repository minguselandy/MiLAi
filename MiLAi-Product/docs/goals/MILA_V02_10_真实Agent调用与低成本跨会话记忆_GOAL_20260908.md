# MiLAi v0.2-10：State 记忆调控、可逆探索与跨会话执行 Goal

## 1. 目标、修订与授权

**以可恢复、可修正的 State 作为外部工作记忆，让一个 Host 在正常工作中协调联想、
聚焦、分支切换与证据约束的收敛，改善复杂问题的回答和跨会话执行。**

本 Goal 的研究对象是“Agent 如何使用记忆参与求解”，而不只是“工具调用是否成功”。
存储、回执、OAuth 和 8 工具是基础；研究变量是可观察的处理策略与行为，不是语义裁剪 Context。
**State 调节现在先关注、先处理什么，不决定模型有权或能够看到哪些合法材料。首版明确排除 projection。**
人类记忆研究与 ADHD 执行功能支持方法提供设计启发，不作为 Agent 效果或临床等价性的证明。

## 3. 研究定位与证据边界

### 3.1 从人类支持方法迁移功能，不模拟疾病或脑区

| 启发来源 | 本 Goal 的工程假设 | 不能外推的结论 |
| --- | --- | --- |
| ADHD CBT 中的组织、任务分解、替代方案及记录干扰念头 | 外部目标锚点；候选先暂存，不立即执行 | 单项技巧已被独立验证有效，或对 Agent 同样有效 |
| 延迟意图的外部提醒 | 保存返回条件和下次第一步，不只保存事实摘要 | 多保存就一定减少成本或提高完成率 |
| 已呈现材料的回溯线索 | 完整材料不变，围绕当前问题重新对照证据 | 软件处理提示等于人脑内部注意力机制 |
| 语义记忆局部/全局搜索 | 当前路线无进展时尝试不同入口，保留返回点 | 固定频率换支必然更好 |
| 创造性与动态脑网络关系 | 将灵活探索与稳定执行一起评估 | 相关性证明提高切换次数可以提高智能 |

对应依据分别是 [Safren 等的整体 CBT 随机试验](https://jamanetwork.com/journals/jama/fullarticle/186469)、
[Gilbert 的意图外部化实验](https://pubmed.ncbi.nlm.nih.gov/25404057/)、
[Rerko 等的 retro-cue 实验](https://pubmed.ncbi.nlm.nih.gov/24442551/)、
[Hills 等的语义觅食研究](https://pubmed.ncbi.nlm.nih.gov/22329683/)、
[Chen 等的脑网络研究](https://www.nature.com/articles/s42003-025-07470-9)。
后四项是一般记忆/认知研究，不全部称为 ADHD 干预。
这里提出的是功能类比与可证伪工程假设，不涉及用户健康推断，也不以医学标签给模型能力背书。

### 3.2 候选贡献与近邻

- [HiAgent](https://arxiv.org/abs/2408.09559) 已用子目标组织工作记忆、替换旧轨迹并保留当前相关材料。
  因而“按子问题管理上下文”本身不是 MiLAi 的独立创新。
- [MemR³](https://arxiv.org/abs/2512.20237) 已研究 retrieve / reflect / answer 路由与 evidence-gap 跟踪。
  因而“决定检索还是回答”也不是独立新颖点。
- [Remember When It Matters](https://arxiv.org/abs/2607.08716) 已研究维护执行记忆并选择性注入提醒，
  使用独立 Memory Agent。MiLAi 首版坚持一个 Host；少一个 Agent 是实现取舍，不自动构成创新证明。
- [Runtime-Independent Persistent Agents](https://arxiv.org/abs/2609.00546) 已研究持久基底、恢复协议和
  受治理的机械连续性，并明确不据此证明行为不变。持久化/恢复本身不作为本 Goal 的核心创新。

本 Goal 集中验证的组合假设是：
**将联想激活、注意力占用、证据采信分离，通过可修正 State 管理可逆探索，
并跨会话保留继续求解的入口。** 文献核对只用于划定近邻，不是穷尽式新颖性审查。

三个研究问题分别归因：

| 编号 | 可检验问题 | 暂不声称 |
| --- | --- | --- |
| H1 | 相同完整材料、基础历史及推理机会下，Host 自产 Control State 是否优于普通复核/简单 focus cue？ | 改写控制字段就证明注意力或行为已改变 |
| H2 | 同检索、生成预算下，候选暂存与可逆换支能否增加有效证据而不增加候选被无依据采信？ | 联想越多、分支越多越好 |
| H3 | 同样返回信息与合法来源下，控制 State 的恢复/使用是否减少重复工作、支持纠错？ | 存储介质本身带来认知优势，或一次冷恢复证明长期净收益 |


## 4. 首版方法合同：State 调节处理策略，不裁剪材料

研究工作名：**State-Regulated Associative Memory / 可恢复 State 记忆调控**。
这是一种 memory regulation，不是新的 Memory Store；取消投影也不自动建立新颖性。

### 4.1 控制关系与非权威边界

用 `S=(G,F,H,B,R)` 描述目标、当前焦点、候选假设、暂停分支、恢复/重审条件。
这是研究抽象，不要求 Runtime 强制此字段集合。

```text
完整合法 Context / Memory + 当前问题 + Control State
    → Host 决定先对照什么、先做什么、哪些念头先暂存
    → Reason / Act → 新 Observation
    → Host 修正 Control State，必要时重开旧问题
```

即 `A_t = π(Q_t, M_t, S_t)`、`S_(t+1) = U(S_t, O_(t+1))`：
State 影响 Host 的使用政策，不改变合法记忆集合 M 本身。
权限、来源版本及预算边界仍由可信 Host/Runtime 执行；State 不是授权凭证。
“控制”是外部任务调控的行为假设，不表示直接操纵 Transformer 注意力权重。

### 4.2 四组处理语义，不是新工具或独立控制 Agent

| 语义 | State 记录/提示什么 | 行为证据与限制 |
| --- | --- | --- |
| `FOCUS` | 当前问题、待对照的判断、优先下一步 | Host 先处理哪个问题、先核对哪些来源；不隐藏其他材料 |
| `ASSOCIATE` | 不同机制的候选和验证入口 | 允许新方向出现；候选不自动成为事实、工具调用或新授权 |
| `PARK / RESUME` | 已查材料、未决项、暂停原因、恢复条件与下一步 | 暂停可逆，恢复不从头定位；暂停不等于删除或为假 |
| `CONVERGE` | 交付所需条件、剩余不确定性、何时应重审 | Host 决定回答或继续；预算耗尽不等于事实已查尽 |

这些操作由同一个 Host 的正常循环承担，不新增 MCP 工具、隐藏 Reviewer 或 Runtime 语义判定器。
结论采信仍是 Host 的证据判断，Canonical 仍需原治理流程。
CONVERGE 的条件必须与当前任务相称，不固定要求“每题至少排除两个解释”等额外探索。

### 4.3 State 内容与可纠正性

| 用途 | 保存的最小外部工作产物 |
| --- | --- |
| 目标锚点 | 当前目标、有效约束及来源入口 |
| 当前焦点 | 当前要判断什么、哪些条件未决、下一步处理什么 |
| 候选联想 | 一行待验证假设及可查入口，不伪装成用户原话或已证事实 |
| 分支返回点 | 已检查什么、为何暂停、回来先做什么 |
| 修正/结束条件 | 哪类观察应重开问题、交付还有什么限制 |

P1 仅采用小型可选 Host 产物 `current_question + unresolved + next_action`。
它可由 JSON、Markdown 或现有 payload 承载，不是新增业务 Schema。
P2 才增加候选/暂停/恢复关系，P3 才验证这些关系的持久化；不同时建设。

State 只记录可见问题、计划、来源和行动结果，不索取、保存或评分私有思维链。
新观察必须能修正旧 State；“已解决”“不要再查”只是可错工作记录，不得用于过滤反证或禁止合法回查。
保存只在有恢复价值的检查点发生，不每个联想提交一个版本。
正确的不作为、保留原焦点、暂不检索、暂不写回都可成为合格结果。

### 4.4 输入与观测合同：availability、presented、attention 分账

- **Availability**：当前主体有权访问的来源、记忆和正常工具能力。State 不缩减这个集合。
- **Presented**：某次实际请求中送入模型的正文、版本与 span；这是归因证据，不是注意力读数。
- **Observable use**：显式处理顺序、实际查询、证据对照、行动和答案。
  不能由“State 写了 focus”推断模型关注了它，也不能从模型没提某段材料断定内部没使用。

E1 的完整冻结来源、正常基础历史、当前任务与新观察在各条件实际请求中保持一致；
变量只有预注册的控制提示/Host 产物。来源块的内容、顺序与呈现位置固定，
变化的控制槽放在同一位置，不通过重排、摘要、隐藏正文或自动追加 gold 片段引入第二种干预。
各组准备轮产生的不同工作产物属于实验变量，不冒充共同历史。

“完整”指实验事前冻结的必要合法材料集合，不是把整个数据库或无限历史塞进每次请求。
若该集合无法在共同上限内完整呈现，停止或另行冻结更小的独立案例；不能语义裁剪后仍记本条件通过。
E2/E3 保留相同来源访问能力和正常访问政策；不同查询取得不同新材料是行为结果，不能强行锁成相同轨迹。

权限过滤、撤权和来源资格检查继续 fail closed；这不是被排除的语义投影。
`payload_withheld=true` 不能回退旧正文缓存，也不能解释成“没有历史”。
已进入旧上下文的受限内容不会因数据库变更自动消失，依既有披露合同处理下一次发送。

首版不实现 State 驱动的 context pruning、compression、selection、隐藏来源或摘要替代正文。
标准 Host 若自动压缩，必须观测是否破坏 E1 的材料一致性；被破坏则该条件不合格，不能归因于控制 State。
这是一项研究范围选择，不是声称所有投影方法无效或都不安全。

### 4.5 存储层次与注意力调控正交

L1 工作/可复用 State、L2 详细记忆、L3 来源回答“信息在哪里”；
FOCUS / ASSOCIATE / PARK / RESUME / CONVERGE 回答“现在怎样使用信息”。
焦点可以直接指向 L3，也可以围绕已经在 Context 中的证据展开；不把 FOCUS 实现成只读 L1。
独立查询和多任务仍可并发，结果按请求/分支归属交还 Host，再使用现有 CAS 协调提交。

### E2：联想、暂存与可逆换支——核心机制实验，独立后续授权

本轮 `NOT_ENTERED`：E1 未提供合格质量/安全收益信号。以下保留未来方法合同，不是待自动执行清单。

研究：维持焦点时容纳新联想，需要时换支，随后凭新观察恢复暂停问题；
同时增加有效证据，而不增加重复探索、目标漂移与 hypothesis-to-fact leakage。
首版仍无 projection，不训练 activation/branch policy，不用相似度、连续重复次数或 novelty 阈值自动 switch。

2×2 的两个因素应可独立操作：

| 控制状态表示 | 普通自主探索，无专门探索提示 | 有通用的有界联想/暂存/换支/收敛提示 |
| --- | --- | --- |
| 无显式 Control State | A：普通 Host / 正常笔记 | B：探索策略提示，仍无强制 Control State 记录 |
| 有显式可更新 Control State | C：显式状态 + 普通自主探索 | D：显式状态 + 探索策略提示 |

列因素是“探索策略提示”，不称为“State 调控”，以避免“无 State 却要求 State 调控”的矛盾。
无显式 State 不表示清空记忆或禁止正常笔记；显式 State 不表示自动多一次模型调用。
B 的通用提示不得偷偷创建等价强制 State，A/C 也不能禁止模型自然产生联想。
C/D 通过同一 Host 正常回合维护控制产物；字段集合、提示差异与更新机会预注册，实际偏离也保留。

选择来源相同、需要区分多个解释且可能出现新反证的短任务；可用合法本地 LME 片段，
完整保留相关材料和干扰，注明已打开/派生/留出属性。后续有效来源/查询轨迹可以因策略而不同，
但初始能力、工具目录、授权、并发、每臂生成/检索上限必须相同。

实际过程应至少能观察：候选出现但未立即切走 → 有依据地暂停/选择下一方向 →
新观察出现后恢复或明确不恢复 → 有限结论。不能以只有一次查询/一次回答宣称验证完整换支链。
State 可记录少量候选、暂停问题和 resume_if / stop condition；记录本身不是进展指标。

当前预算仅规划 A/D 两臂的低成本机制 pilot，每臂至多 4 次生成、6 次搜索/读取。
A/D 只能评估组合政策，不能分离两个因素或估计交互作用。
完整四臂须另行批准足以保持每臂相同回合数的预算；不把原来的两臂额度除以四导致恢复链无法发生。
只有四格齐备，才讨论 D−C、B−A 及其差异；一个案例也不足以声称稳定交互效果。

主结果并列报告 **Useful Evidence Gain、Unsupported Adoption、Exploration Cost**，不强压综合分：
有效新证据需帮助任务判断，不仅是新增文档 ID；候选污染按可评价运行/候选的明确分母统计，
不靠词面相同判定。另报重复查询、目标漂移、暂停后恢复质量、纠正能力和错误收敛。
这些以公开动作、结果和短状态产物为依据，不索取内部思维链。

什么时候 switch 由 Host 决定。预算、身份、版本和工具安全由机械层保证，
不能因 State 写了“探索分支”就自动获得行动预算。普通同预算探索已足够就不增加策略复杂度。

### E3：控制记忆的真实冷恢复——独立后续批次

本轮 `NOT_ENTERED`：随否定诊断关闭扩张；未执行持久化/冷恢复比较，不据 E1/B2 推断 H3。

先冻结同一次 Host 正常工作形成的返回信息：目标、当前问题、合法来源、未完成分支、
已查结果、返回第一步和不确定性。只用自然产生的内容；若来自人工种子，另列受控机制条件。

1. **内容匹配**：普通版本化笔记/文件和 MiLAi State 都得到相同返回信息。
   不只给 State 分支与下一步，却让对照只读一份缺失信息的最终摘要。
2. **正常恢复**：两组都有明确、可信的任务定位与正常启动读取。跨 session 保持正确 TASK 绑定，
   不用同一个默认 task scope 假装多任务隔离。Host 启动读取是生命周期能力，不算模型自主召回。
3. **真正冷启动**：结束原会话并清空临时输入；新进程/新会话只共享冻结的正常产物、合法来源
   及该组允许的记忆。G 的未授权日志、隐藏摘要、缓存和对方派生材料不进入请求。
4. **隔离调控效果**：先用零模型检查验证两种存储可恢复同样信息。
   语义比较固定内容、来源、启动规则和调用预算，只比较正常笔记使用与 State 调控策略；
   结论属于恢复后的使用政策，不归因于 PostgreSQL、JSON 格式或 MiLAi 存储名称。
   若两组实际输入/策略完全相同，不为证明存储优势重复花模型调用。
5. **实际使用**：检查首次相关动作、重复搜索、暂停分支恢复，以及新观察能否推翻旧“已解决”。
   正确保留旧分支、不必再查、不写回也可通过。普通笔记表现相同应诚实保留。
6. **真实产品路径**：State 保存/读取使用现有公开 MCP，CAS 与 operation_id 按正常 Host 管理；
   模拟 Host 不冒充原生 Codex。模型生成的工具调用与机械启动读取分别统计。

一次续做只回答条件化恢复价值，不证明自主保存策略、整体产品净收益或长期维护。
自然端到端 G→R、无人提示的检索触发与多轮过时修正仍需独立设计/授权；
必须包含未保存、NO_CHANGE 和失败任务，不能只挑正确 State。


## 7. 必要负控与可观察验收

| 控制 | 机械准备检查 | 后续真实模型观察 |
| --- | --- | --- |
| 错焦点/旧“已解决” | 反证仍完整呈现，旧 State 无过滤/授权权力 | 能否纠正当前问题、重开判断，而非盲信旧记录 |
| 诱人但无关的候选 | 候选文本不会直接执行工具或改变额度 | 能否保留念头但不偏航，不把假设当事实 |
| 有价值的暂停分支 | 来源与返回点可读取，暂停不删材料 | 新观察后能否接续或合理选择不恢复 |
| 当前信息已足够 | 直接回答可用，不强制检索/保存 | 是否保持轻量，避免为形成 State 多做无用动作 |
| 来源不可用/撤权 | 披露资格、失效和超限显式反馈 | 不把 unavailable / withheld 当作没有历史或事实不存在 |

首个追加语义负控批次优先检查“错误旧 State + 新反证”及“无需干预”，
固定受控起点、材料与预算，对比简单方案和控制 State；不冒充自然错误发生率。
机械测试不能替代这些语义结果。

统一记录首次相关答案/动作、有效证据利用、必要条件覆盖、目标漂移、候选污染、
恢复/重复工作与完整成本。presented 是实际输入证据，不是 attention 实现或评分。
Control State 与工具结果都是可错材料；State 格式变化不能替代行为变化。

全部预注册分配进入总表，包括 NO_CHANGE、未调用、非法参数、无有效状态、预算退出、人工阻断和失败。
适用分母分别报告；一个任务的多条件/多次续做不是多个独立 family。
O 单列，不能并入自主成功率；无法判断的语义归因保留 unknown。
小 pilot 用于定位机制、估成本和决定是否继续，不承诺统计显著性、稳定泛化或长期净收益。
