## 3. 研究主张与近邻边界

### 3.1 E1、E2、E3 的主张必须分开

| 假设 | 可检验问题 | 不构成的证明 |
| --- | --- | --- |
| H1 静态前置能力 | 同一完整材料下，自产处理状态是否优于普通复核/通用 cue；相对 R0 是否值得多一轮？ | 动态修正、联想、换支、持久化或完整 memory regulation |
| H2 动态调控 | 同搜索能力与预算下，可暂存、可恢复的候选控制能否增加任务有效证据，同时降低或不增加候选污染，并恰当重开问题？ | branch 数量即收益；两臂组合胜出即每个组件有效 |
| H3 持久调控 | 同信息冷恢复后，control-state-aware 使用政策能否减少重复工作、恢复正确分支，并纠正旧控制判断？ | 数据库或 State 名称本身改善认知；一次续做证明长期维护回本 |

E1 是 **Static Focus-State Affordance Test**，不是论文核心创新的完成证据。
E2 检验动态关系，E3b 检验该关系跨会话后能否正确使用；通过其中一项不替代其余项。

### 3.2 近邻核对与候选差异

以下针对 2026-09-08 访问的论文/作者资料，属于范围核对，不是完整新颖性审查。

- **Remember When It Matters** 已直面“信息仍在轨迹或 Context 中却不再影响行为”。
  它用独立 Memory Agent 维护结构化 bank，包括进度、未决问题、任务事实、失败与程序经验，
  再选择注入针对性提醒或保持静默；实验包含 full-bank exposure、always-inject、
  无 bank 的指导及 Mem0 对照。不能将其弱化为普通 RAG，也不能以“自产提醒改善答案”建立独立创新。
  见论文 [§3、§4.3](https://arxiv.org/html/2607.08716v1)。
- **Context-Folding** 已支持临时 sub-trajectory 的 branch、摘要 return 与折叠中间上下文。
  因而 PARK/RESUME 的存在本身不是新颖点；本 Goal 排除这类语义折叠干预，重点检查暂停判断
  如何被新观察纠正，以及控制关系的冷恢复。见[论文](https://arxiv.org/abs/2510.11967)和
  [作者项目页](https://context-folding.github.io/)。
- **Runtime-Independent Persistent Agents** 将持久基底、运行环境替换与授权连续性分开，
  并区分机械连续性和行为保持；它支持本 Goal 将 E3a 与 E3b 分账，而不是把机械恢复当认知结果。
  见[论文](https://arxiv.org/html/2609.00546v1)。
- [HiAgent](https://arxiv.org/abs/2408.09559) 的子目标工作记忆、
  [MemR³](https://arxiv.org/abs/2512.20237) 的检索/反思/回答路由仍是既有近邻；
  本轮没有新增它们的复现或效果比较。

**候选贡献是单一 Host 下“候选与采信分离、暂停判断可纠正、控制关系可跨冷会话恢复”的组合。**
单一 Host 主要是简洁性/成本取舍；无 projection 是变量控制；两者都不自动证明新颖性。
若未来提出机制论文主张，应按所声称组件补直接对照，不凭这些概念的组合宣称优于近邻。

### 3.3 人类启发不等于效果证据

沿用 v0.4 对组织、记录干扰念头并延迟行动、外部提醒和可逆搜索的功能类比。
[Safren 等整体 CBT 试验](https://jamanetwork.com/journals/jama/fullarticle/186469)
不证明单个技巧或 Agent 干预有效；不模拟疾病、脑区或内部注意力权重。
本文研究公开行为，不索取、保存或评分私有思维链。

## 4. 方法边界：State 是可错工作数据，不是信息或行动授权

| 处理语义 | 用途 | 不能发生的升级 |
| --- | --- | --- |
| FOCUS | 当前问题、待比较条件、优先下一步 | 控制正文可见性或覆盖用户当前目标 |
| ASSOCIATE | 保留可能有用的解释与查证入口 | 候选自动成为事实、工具调用或行动预算 |
| PARK / RESUME | 暂停原因、已查结果、返回条件与第一步 | 暂停等于删除/为假；旧“无价值”禁止回查 |
| CONVERGE | 明确交付条件及应重审的观察 | 预算耗尽等于证据已查尽或问题永远关闭 |

可信 Host 使用协议规定如何核对、使用和修正 State；State 的 `next_action` 只是待核验计划。
模型或脚本不能因为 State 写了“直接提交”而执行工具、提升权限或绕过 Canonical 治理。
Runtime 保持来源、权限、CAS、幂等、TTL 与披露检查，不判断语义进展，不训练或硬编码 switch 阈值。
候选出现、保存或被检索返回，都不意味着它已被证据支持。

### 4.1 输入与观测

- Availability：当前合法来源和正常工具能力，不因控制 State 而缩减。
- Presented：实际请求里的正文、版本/span、顺序和位置，不等于模型内部注意力。
- Observable use：公开对照对象、查询、分支处理、答案和行动，不由字段名出现推断。

E1 各条件交付看到相同完整冻结来源、基础历史、任务与新观察，来源块位置固定，
控制产物位于共同位置的独立槽；不同产物是实验变量，不能藏成共同历史。
“完整”不是整个数据库无限加载。若完整冻结集合超预算，停止或另行冻结独立小案例，
不得偷偷去掉干扰、重排来源、摘要替代正文或自动补 gold。
E2/E3 保持相同初始材料及来源访问能力；后续查询轨迹可以因政策而不同，并据实记录。
首版不实现 State 驱动的 context pruning、compression、selection 或 folding；
标准 Host 自动压缩破坏 E1 条件时记执行不合格，不归因为 State 效果。

权限、撤权和资格过滤继续 fail closed；`payload_withheld=true` 不回退旧正文，
也不解释成“没有历史”。已经进入旧 Context 的内容不会因数据库变化自动消失，
后续发送仍须符合既有披露合同。L1/L2/L3 是存储/访问层次，与注意力调控正交；
已知来源可直接读 L3，不强制按层串行。独立查询和多任务并发保持不变。

### 7.2 主张、指标与决定

- C2−C1 / C2−C0：在等两轮下比较自产处理状态政策的静态增量；

- 所有组一样正确时，按完整成本保留更简单方案；小样本没有观察到差异不等于统计等价。
  质量或安全不合格时，少量 token 节省不能作为保留候选的依据。
- O 仅诊断，人工成本单列，不计自主成功率，不称数学上界；未运行记 NOT_RUN。

记录 material_presentation_equal、focus_task_fit、observable_processing、
required_condition_omission、unsupported_adoption，以及首次交付完整正确性和全成本。

branch switching、持久化或冷恢复。** 它决定是否保留显式 FOCUS，不机械决定 H2 能否研究。

### 8.1 进入规则与最小干预

事前记录可观察失败：重复同一路线无进展、候选抢占主任务、暂停位置丢失，
或新观察出现后仍盲从旧关闭判断；区分来源未取回、已呈现未使用与权限/工具错误。
可来自已有正常轨迹，或明确标记的受控机制案例；后者不代表自然发生率。
为每次进入登记 failure/source ID、作用层、拟变因素、对照、可观察预测、预算与停止条件。

| E1 / 动态证据 | 后续决定 |
| --- | --- |
| 显式 FOCUS 有合格增量，且另有动态失败 | 可保留该 FOCUS，再检验最小动态干预 |
| 简单 cue 足够，或未证明显式 FOCUS 增益，但有动态失败 | 使用更简单焦点机制，只研究必要的候选/暂停/恢复 |
| E1 均无合格收益，但存在独立动态失败 | H2 仍可单独提出，不能复用已失败的不安全动作政策 |
| 没有动态失败或不能区分失败层 | 不进入 E2，不因阶段编号或“核心创新”扩张 |

H1 阴性不是 H2 阴性；但独立失败也不是绕过通用权限、安全和执行有效性检查的理由。
v0.4 的既有失败不删除，新机制不得按旧 case ID 定制提示或强制正确分支。

## 9. E3：Persistent Regulation——机械恢复与行为恢复分离

自然产生与人工种子分开；若筛选了合格产物，只能作条件化机制实验，

### 9.1 E3a：机械恢复价值，零模型

将相同返回信息分别置于强简单的普通版本化笔记/文件与 MiLAi Working State，
采用各自正常合法接口，比较：

- 保存确认、重启恢复、内容/版本一致性和提交结果未知的核对；
- 稳定 TASK 绑定、并发/CAS、作用域与权限隔离；
- 过时/撤权/不可读处理、失败语义、读取延迟和集成所需操作；
- 写入、恢复与工程配置成本；人工/GPU 未观测成本不填零。

不故意剥夺普通文件的正常版本控制、定位、备份或锁能力；
不支持的能力记 NOT_SUPPORTED，不编造两系统契约等价。
涉及持久写入、冲突或权限测试，只用获准的独占合成域；已有适用证据可复用并声明版本，
不重复运行无变化的大压测。零模型不等于零资源或默认获准改数据库。

这一步只产生基础设施结果，不运行模型回答来证明存储名称有认知优势。
机械恢复不能可靠完成时，不把缺失信息当政策失效继续 E3b。

### 9.2 E3b：控制策略跨会话价值，才使用模型

冻结同一来源、目标、历史产物、返回信息、新观察、模型与预算。
优先让两臂采用相同载体和同一份返回正文，**只改变 Host 的恢复使用协议**：

| 条件 | 相同返回信息的使用方式 |
| --- | --- |
| N：normal note-use | 正常读取笔记并自主继续，保留完整合法工具能力 |
| S：control-state-aware resume | 按冻结协议核对旧控制记录与当前观察，判断保留、重开或改变下一步 |

N 不得缺少分支、返回条件或下一步；S 不得额外获得隐藏摘要、正确焦点或评价结论。
两臂都正常启动读取，不把 N 故意设置成必须自行发现记忆才算成功。
S 的使用协议由可信 Host 配置，不让数据库返回内容自动升级为指令。
若两臂实际输入和使用政策完全相同，不为证明 State 存储优势重复花模型调用。
若不可避免同时改变载体、表示或恢复时机，标为组合比较，不作纯政策归因。

真正结束原会话并清空临时上下文；新进程/新会话只获得冻结的正常产物与合法来源。
共同起点在分叉前冻结；其他臂产物、生成后的日志、隐藏缓存、评价材料不得泄漏。
State 路径用现有公开 MCP、可信 TASK 绑定、CAS 和 operation_id；
机械启动读取不算模型自主 MCP 触发，模拟 Host 不冒充原生客户端验收。

B4 默认上限对应两个情景——应重开、无需重开——各两政策、各一次首次交付，共 4 次生成。
这是首次冷恢复行为比较，不足以证明多轮持续调控。新 G、额外续做轮数或更多情景须另立预算。
记录正确下一步、重复定位、分支恢复、Reopen Correctness、无必要重开、
盲从旧 next_action、新无依据建议和完整生命周期成本。
写入和控制信息生成成本单列分摊，不能只报冷恢复后 token 节省。

一次冷恢复只证明条件化使用价值。整体产品净收益、自然自主保存和长期维护须独立端到端设计，
包含 NO_CHANGE、不保存、不恢复和失败任务，不能只筛成功更新。

## 10. 核心安全与行为指标：稳定且可修正

### 10.1 错误控制 State 是核心负控

控制错误包括旧“已解决”“别再查”“该分支无价值”“下一步直接提交”，
不要求事实资料本身错误。每类“需要重开”情景配一个“不需要重开”的匹配观察：
后者的新观察与旧控制判断不构成冲突，不应一律重启全部探索。

| 指标 | 适用分母与成功条件 |
| --- | --- |
| Reopen Correctness | 事前标注确需重新核验的机会中，在首次相关不当行动前重开正确问题，并改变/暂停旧错误下一步；只改状态文字不算 |
| Unnecessary Reopen | 无需重开的匹配机会中，无依据地重启已成立分支或扩大探索的比例；必要的轻量核对不算重开 |
| Stale-action Follow-through | 有反证时仍按旧错误 next_action 建议或执行的机会比例；建议和实际执行分别记 |
| Post-correction Unsupported Adoption | 纠正旧判断后又引入无依据事实/建议的运行或可评价命题比例；明确分母，不混成目标纠错率 |

分母为 0 时记 N/A，不填 100%；证据不足以判定应否重开时记 unknown。
观察必须真的进入相应请求，判断足以挑战旧控制不等于已证明竞争解释正确。
“重开”应服务当前任务，不要求所有新观察都导致重开，也不奖励分支切换次数。
旧 B2 的目标纠正 2/2 不能据此改判为本版完整恢复安全通过。

### 10.2 其他负控与全量记录

保留诱人但无关候选、有用暂停分支、充分信息无需干预、不可用/撤权来源等检查。
B2 小批优先是“错误旧控制＋新反证”和“新观察不冲突、无需重开”，
各比较同信息普通记录与候选控制政策；人工注入须明确标记，不称自然错误发生率。
若 E2/E3 的已登记分配可覆盖同一观测，避免额外重复调用，但不能重复计为独立样本。

全部分配进入结果表，包括 NO_CHANGE、无有效状态、格式错误、未调用、超限、阻断和失败。
正确不检索、不换支、不保存均可得分；单任务多条件不是多个独立 family。
小 pilot 只定位机制、失败形态与成本，不承诺稳定效应、统计等价、泛化或长期净收益。
不以关键词命中、State 字段更新或不可观察的内部推理替代语义验收。
