## 2. 要回答什么，不先假设答案

主问题：**在正常记忆、正常工具与来源访问都存在时，简单方案的成功区间、成本压力区间、
失败区间分别是什么？最早可证实的失败层在哪里？**

“Failure regime / 相变区域”在本 Goal 只是工作比喻，不预设存在突变点、统一临界负荷或
某个必然失败的压力。允许结果是“当前测试范围内简单方案仍然足够”。

希望观察到的是任务条件与行为之间的关系，而不是证明 FOCUS/PARK/RESUME 的必要性。
新重复模式可能指向取证、普通推理、任务合同、资源或记忆使用；不预选 memory-induced
inertia、ADHD-inspired regulation 或其他候选作为最终解释。

## 3. 强简单基线与共同底座

默认参考是 **普通笔记 + 简单提醒 + 正常工具 + 正常合法来源访问**，不是无记忆或被削弱的
历史 A0。可以同时观察纯 NOTES 作为较轻参考，但简单提醒已经能解决的问题不应自动
成为复杂机制的动机。NOTES 与 NOTES+REMINDER 的计数分别报告，不混合成一组结果。

| 必须保留的能力 | 本阶段含义 |
| --- | --- |
| 普通记忆 | 自由文本笔记，可以自然记录目标、候选、暂停原因、下一步；不禁止其自然产生控制信息 |
| 简单提醒 | 固定、领域无关的来源/适用性核对提醒；不包含题号、gold、正确方向或动态调控算法 |
| 正常取得 | 来源 inventory/search/read、必要分页、版本绑定、实际呈现回执和有界独立读取并发 |
| 正常交付 | 共用已修复的 readiness-first、非空工具输入、明确澄清与最终槽；不重引入旧空调用缺陷 |
| 正常保存/恢复 | 可选保存，真实提交回执、CAS、冷 Host 公开读回；不强迫每轮记事、不隐藏自选写入失败 |
| 安全权限 | 可信任务/身份绑定，所有来源保持原授权，非 Canonical 笔记不增加治理或行动权力 |

## 4. 六个环境压力维度

以下是可选择的压力轴，不是六个必须跑满的模块或全因子矩阵。强度用实际量记录，
“低/中/高”只作图谱标签；它们不在现在被固定成必跑任务数。

| 压力轴 | 可改变的环境条件 | 重点观察 | 必须分开的混杂 |
| --- | --- | --- | --- |
| P1 中断与恢复 | 中断点、间隔任务/事件数、来源变化、冷/热恢复 | 恢复事实但丢失当前问题、返回入口或未决约束 | 墙钟等待、历史干扰、真实环境变化与进程重建不是同一变量 |
| P2 多任务交错 | 活跃任务数、切换次数、更新抵达次序 | 串用任务结论、漏接未决问题、重复定位 | Host 任务绑定错误/权限泄漏先算工程或安全问题 |
| P3 多种合理解释 | 竞争解释数量、干扰相关性、需要跨源联系的距离 | 第一解释固着、无节制探索、候选污染 | 来源不可得、检索线索过弱和一般推理错误不能归为调控失灵 |
| P4 反证与判断更新 | 新证据强度、对象/范围、延迟、更新次数 | 明确反证后仍沿用旧前提，或无关更新引发错误重开 | 新消息不必更真；保留权限、来源可信度与适用范围判断 |
| P5 局部完成与暂停分支 | 独立子问题/暂停点数、待外部输入、相关或无关恢复线索 | 丢失暂停原因、错误续做、不该恢复却恢复 | 不强制 baseline 使用 PARK 字段，行为上的未完成问题才是观察对象 |
| P6 记忆累积 | 笔记/提醒数量、有效信息比例、版本冲突与重复程度 | 提醒泛滥、旧记录覆盖当前约束、恢复成本上升 | 规模、来源覆盖、检索排名与 context 物理容量分别计量 |

长时间中断不靠让服务空等来制造“遗忘”。如果模型输入与外部状态未改变，墙钟变长本身
不能被当成认知负荷证据。优先记录实际冷边界、间隔活动及来源更新；用模拟日期表达
时间时注明 SIMULATED_TIME，不宣称真实数周部署效果。来源因权限/保留策略到期属于可用性。

开始宜从单个压力轴或一个清楚的组合入手，先有可完成的低压参考，再逐步改变环境。
可按已见现象提高、降低、换轴或组合压力；选择依据及全部 run 留存，不能只保留最先失败点。
不以删除关键证据、强制不记笔记、禁止正常检索或缩小预算来“证明普通记忆不行”。
超过资源上限的失败如实入图，不为了得到语义失误把它改名为认知极限。

## 5. 三类优先探针，不预设解法

### 5.1 多任务交错

场景骨架可以是 A 未完成 → B → C → 回 A → B 收到新观察 → 回 B。
任务各自有自然目标、正常产物、公开来源和任务绑定；未决事项可以保存在普通笔记。
切换次序与外部更新先记录为环境事件，不由某组是否保存成功决定。

只在单一获授权实验主体的合法任务范围内交错。不得用跨租户资料混合制造压力；
未授权内容一旦可见先暂停安全检查。Agent 把合法但不属于当前任务的约束用错，才进入
任务串扰的行为诊断。不同任务是否能访问彼此资料，按既定授权明确，不临时放宽权限。

### 5.2 新证据推翻旧判断

让 Agent 在最初不完整但合法的资料下自然形成暂定判断，再给出有关/无关的新来源。
例如数据库假设后来遇到等待很低、文件同步长尾等观察；这些只是场景类型，不是特定题的
固定正确答案。新证据需足以区分解释，否则应保持未决，不能把谨慎当作固着。

以 baseline 自己形成的可错笔记为主。若注入错误交接，只标 CONTROLLED_INJECTION 并
单列，不再把自制错误笔记的失效误称自然 memory failure。未知或弱证据不能机械覆盖
旧结论；加入无关变化和旧判断仍成立的记录，观察稳定性是否也被保留。

### 5.3 干扰中的关联

任务可以有显眼但最终错误的解释、需要跨来源才能建立的关联和若干合理干扰项；这属于
环境构造，正确关系只在 evaluator 侧，不写入 Host 的“请换方向/请发散”提示。
普通基线自由查询、形成候选或记录笔记；不规定必须找到哪条联想路线，也接受等价正确方法。

观测第一条假设是否占据行动、远关联是否自然找到、是否取得依据后才采信，以及是否
回到已经排除的方向。没有形成某个命名候选不自动扣分，任务直接正确完成也是有效结果。

## 6. 探索策略：找边界，不反复造一个更难的失败

复用已打开 benchmark、真实任务快照或标明来源的合成压力版本，先选择具可观察性的
材料，不要求先建满大题池。相同根任务的压力变体/seed/冷启动仍属同一 cluster；
跨两个领域但复制同一前提工作流，不能冒充充分异质性。

任务与压力可自适应改变；每次发送前存档本次条件、选择理由与研究者已经知道的结果。
发现失败后，优先区分普通取得/交付问题、检查低压或弱压力回退、以及换一个不同根场景
能否出现相似行为。不必依次完成全部检查，也不要求任一失败都持续加压到所有组都失败。

保留成功区间、低压本来就失败的任务、资源不足和不确定评价。可以偏向信息量高的失败，
但最终只能报告选择过的探索轨迹，不能计算无偏自然错误率或通用临界阈值。
已打开旧案例可以参与 development；旧 Horizon/Mem2Act/LME 保护池仍不自动开放。

选择/修改任务时不把 case ID、gold 词或题专属查询规则加入基线。环境正文与参考答案
可在 discovery 中修改，但变更前后分别版本化，旧运行与旧评价不能覆盖。
不存在“必须出现惯性”或“必须产出至少一个新机制”的验收要求。

## 7. 失败图谱的归因顺序

先记录最早**可证实**的失败层；下游不可观察时保留 UNKNOWN，不用推测补链。
可以附加次级现象，但每个 earliest-layer 汇总只计一次，不重复加总成更多失败。

| 最早可证实的状态 | 如何记录 | 不能推出 |
| --- | --- | --- |
| 资料缺失/任务无法裁定 | SOURCE_UNAVAILABLE / TASK_AMBIGUOUS / MODALITY_UNSUPPORTED | 不等于记忆忘记或 State 表达不足 |
| 未发起必要取得 | ACQUISITION_NOT_ATTEMPTED | 不自动等于 attention controller 有必要 |
| 搜索/读取未取得支持 | RETRIEVAL_OR_REPRESENTATION_FAILURE | 不等于已看见而不愿使用 |
| 取得但未证实进入请求 | PRESENTATION_FAILURE_OR_UNKNOWN | 不计“充分证据下仍用错” |
| 支持已呈现但错误使用 | PRESENTED_SUPPORT_USE_FAILURE，附一般推理/适用性/跨任务等可观察标签 | 不自动归因 persistent memory 或关系 schema |
| 判断/笔记存在但未合法交付 | DELIVERY_FAILURE | 不把隐藏字段或未提交意图抢救成成功 |
| 容量/配额/时限停止 | RESOURCE_LIMIT | 不把 context overflow 或预算不足计为认知机制失败 |
| 输出不足以裁定 | DISPUTED / ATTRIBUTION_UNKNOWN | 不为了结束本批强制二值化 |

发生早期资源停止、来源不足时也保留已观察的行为；只是不声称后续层已经接受了测试。
正确答案同样不保证整条 memory chain 正确，需要注明是否真的使用记忆/来源。

### “旧前提保持”不直接等于“记忆诱发惯性”

描述性标记 POST_UPDATE_OLD_PREMISE_PERSISTENCE 至少需能定位：旧暂定判断/笔记、
针对同一对象与适用范围的有效新支持、其实际呈现，以及此后仍依赖旧前提的可观察动作。
若反证尚未呈现、相关性不清或新旧来源有合理争议，不能满足该标记。

即使满足，也只证明新证据后出现旧前提保持。要称 **memory-induced**，后续须另立
匹配反事实/消融，排除当前上下文锚定、一般推理、证据强弱和提示顺序等解释；
本 Goal 不用时间先后、引用过旧笔记或减少记忆后的单例成功替代因果证明。

## 8. 固定少量观测，保留完整原始记录

用户侧 failure map 每行仅需回答：

| 字段组 | 内容 |
| --- | --- |
| 条件 | task/cluster、基线版本、压力轴与实际强度、冷/热状态、变体/暴露关联 |
| 结果 | 成功/失败/合理澄清/不可裁定，首次错误事件及证据链接 |
| 行为 | 重复工作、旧前提保持、错误重开、遗漏未决分支、无依据采信；没有机会则 N/A |
| 成本 | 全部生成/重发输入、工具、保存/恢复、耗时及未测量项 |
| 解释 | 最早失败层、次级现象、替代解释、为什么下次升/降/换压力 |

底层仍复用既有实际 prompt/State/来源版本/工具返回/发送回执/输出/usage 账本，不增加
隐藏 Reader、自动 Judge 或新的 Runtime 观测语义。原始制品在 Git 外受控目录，Git 只留
摘要/manifest/hash；不要求导出模型完整隐式推理，不保存令牌等凭据。

首次错误以可见事件定位，不猜模型何时“心里已经固着”。重复读取可能是必要重核，
无交付不等于零污染；新候选仅被提出/检索不等于采信。回忆出事实却做错下一步分开记录。
要计算某个率，必须同时报告可裁定分母及机会定义；探索中新增指标标 POST_HOC_EXPLORATORY。
统一污染率若无可靠 claim-unit 标注则不计算，不能继续用无依据的精确比率。

评价可用确定性动作/参数检查和非盲离线语义复核；原参考与后续修改都保留版本，
gold 不进入在线 Host。报告 attempted/delivered/scorable、根 cluster 和重复次数，不把
相关变体混成独立 N。评审劳动与 Provider 用量分账；新 Judge 调用当前授权为零。

## 9. 图谱如何导向下一步，但不自动实现机制

| 探索现象 | 当前处理 |
| --- | --- |
| 普通笔记/提醒在已测压力下仍成功 | 记下已测边界及成本；允许结束，不继续加难度直到必败 |
| NOTES 失败，简单提醒即可工作 | 标 SIMPLE_REMEDY_AVAILABLE；复杂 State 动机不足 |
| 简单方案正确但代价增长 | 标 COST_STRESS，报告质量—成本取舍，不伪造语义失效 |
| 主要是来源/检索/呈现问题 | 转为该层待解决问题，不设计控制 State；必要工程另记 |
| 主要是一般推理、词义或任务歧义 | 留作 reader/task-contract 诊断，不命名新 Memory 理论 |
| 出现有边界的重复 use failure | 形成描述性 failure-pattern 卡，保留支持、反例及替代解释；尚不开发机制 |

“重复”不规定旧 3 cluster × 2 ability 的机械门，也不能由同一根反复失败来替代异质证据。
报告涉及多少独立根/任务结构、什么压力下出现、什么条件下消失、是否只在一个模型配置
成立；这些信息决定是否值得**另提**最小机制，而不是直接证明它是主瓶颈或有新颖性。

## 10. Memory Plasticity / Stability：保留为问题，不实现评分器

可以将本阶段可能积累的现象暂称“记忆稳定性—可修正性调节”：稳定地保留目标、经验和
工作入口，同时允许足够新证据降低旧判断对行为的影响。**记忆存在 ≠ 应一直支配当前行动**。

这不是已证实的新机制，也不把 Influence(m,t) 写成必须实现的 relevance/recency/support
加权器。没有可靠反证时保留旧判断可能正确；新 observation、时间更近或更频繁出现也不
自动拥有更高事实权威。注意力影响、可信度与权限继续分离。

只有出现值得解释的模式，才更新最近邻检索并提出最小干预/强简单对照；本 Goal 不作
论文级新颖性判断，不声称首次研究稳定性或可塑性，不直接将人类/ADHD 启发外推为 Agent 效果。
未来机制若仍不超过普通笔记与提醒，应删除该增量，不能因工作名好听而保留。
