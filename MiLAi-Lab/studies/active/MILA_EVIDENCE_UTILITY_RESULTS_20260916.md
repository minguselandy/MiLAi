# 证据与效用改进：问题与结果（开发中）

唯一求解模型为 Qwen3.6-35B-A3B-FP8。新版本开发中，已有功能实跑，尚无正式确认成绩。

## 首批功能实跑

已暴露开发题中，数据库 **0/2**、操作系统 **2/2**；共 **22 次生成、47,177 tokens**，无未知用量。没有同条件对照，不能据此估计改进收益。

- **真实空采用已出现：** OS 428 检索到经验后选择不采用，实际请求没有该经验正文或消费说明，任务仍完成。采用调用成本已计入。
- **数据库问题仍在：** DB 62 扫描与检查占满三轮后仍未交付；DB 248 虽完成交付，但将折扣降低 10% 写成减去 10，原生评分错误。程序执行成功不等于任务正确。
- **版本归属与恢复：** 实际请求散列、呈现版本及全角色费用已逐项核对；H 条件没有向方法提供原生标签。真实银行跨进程恢复通过。本批未产生自然修订，不能声称已证明新版修订收益。

候选首批 40 项邻近测试及静态、构建检查通过；完整回归待集成后集中执行。共同条件下的旅行完整组及新来源确认仍待完成。

## OM 容量修复

- **找到真实膨胀来源：** 旅行 31 失败前，遗漏页面目录有 309 条、约 6.2 万字符，比观察正文还长。已改为有界引用，完整目录可分页读取。
- **同一失败输入可装入：** 按原生模板重建请求，旧版再次报容量不足；新版完整输入为 60,710 tokens，连同 4,096 输出预留和 256 余量可装入 65,536 窗口。必需任务材料保持不变。
- **真实整理已运行：** 3 次观察、1 次归并，共处理 183 页；325 页仍标为未处理。23 组旧观察被归并结果替换，原始来源保留。跨进程恢复核对了 88 个旧引用和全部 1,603 页范围。
- **成本仍需优化：** 本次维护消耗 **208,981 tokens**。装配器继续填入可容纳的历史原文，最终输入仍约 6.1 万 tokens，不能把摘要缩短宣称为总体节省。这是已暴露材料的容量诊断，没有新增旅行任务成绩。

新版还修复了仅凭页码抑制整理的问题：现在按完整请求指纹避免无进展重试。相关测试与静态、构建检查通过；完整组效果待验证。

## 七次旧经验修订的核查

逐条核对了旧正文、原始来源、修改依据、同流剩余任务及真正发送的请求。七次均为任务结束后修订；只有两次新版进入后续请求。

| 修订任务 | 发现的问题／修改 | 后续结果 |
| --- | --- | --- |
| DB 265 | 将聚合例子由车辆费用换成导游经验年限，未发现被纠正的旧错误 | 剩余 8 题未检索该卡；其中仍有聚合任务 |
| DB 235 | 将 UPDATE 例子换成 INSERT；原生提示本已说明写操作返回 `[]` 的含义 | 新版进入 DB 492；一次 INSERT 后交付，正确。旧版已有同一原则，无法归因于这次改写 |
| DB 324 | 扩展到数量聚合；理由称无需修订，却仍提交补丁 | 剩余 7 题无暴露，含相关聚合任务 |
| DB 482 | 换成客户消费聚合例子 | 只剩 1 道 INSERT 题，无暴露，后续适用机会有限 |
| OS 162 | 从文件不存在推测环境重置，并增加验证建议 | 原生解析器拼接所有 Bash 块；示例脚本先执行 `exit`，可解释后面的建文件命令未执行。无证据证明环境重置；后续无暴露 |
| OS 328 | 认为旧例子的 `touch`、`ln -s`、`chgrp` 是幻觉，替换为当前任务命令 | 原来源确实包含这些命令，修订理由错误。新版进入 OS 460，单个 Bash 块后完成且答对，不能证明纠错收益 |
| OS 333 | 用日志错误计数例子替换原单块脚本例子，核心规则不变 | 剩余 5 题未检索该卡，含相关计数任务 |

**开发依据：** 区分“当前不适用”和“旧经验错误”；修订前能核对原来源；不把例子刷新计为纠错。结果绑定实际发送的版本序列，任务结束后产生的新版本不得取得刚结束任务的使用成绩。
