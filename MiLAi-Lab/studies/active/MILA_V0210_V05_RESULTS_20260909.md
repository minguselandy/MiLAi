## Mechanical recovery and its limits

The same human-constructed return text was saved in Git notes and public TASK Working
State. Git retains immutable commits, a host-selected stable directory, an exclusive
writer lock, version CAS, fsync and operation receipts. State uses trusted TASK/principal/
project binding, `state_id`, current version CAS and `operation_id`; all calls use the
compact eight-tool MCP 0.1.15 delivery, client 0.1.3 and Runtime 0.1.4 on owned PostgreSQL.
Installed Python files match all three wheels: 21 MCP, 14 client, 252 Runtime files.

| Capability | Git notes | Working State |
| --- | --- | --- |
| Confirmation, content/version after new process | PASS | PASS, new MCP process and four later cold startup reads |
| Receipt lost after commit, identical operation replay | Original committed version recovered | Original committed version recovered with replay receipt |
| Two writers at the same expected version | One accepted, one stale | One accepted, one public MCP conflict |
| TASK selection/isolation | Stable host-selected directory; POSIX 0700, same UID is not a principal boundary | Other TASK, principal and project each return ABSENT |
| Unreadable dependency | Requires application eligibility checks | Invalid Evidence reference rejected |
| Revoked dependency | Not a native Git capability | Separate captured synthetic Evidence revoked publicly; dependent State GET withholds payload and reports warning |

Receipt loss was injected at the Host boundary **after commit**, not a network partition
or power-loss test. Process restart is covered; database crash recovery, TTL expiry,
hostile same-UID isolation and physical purge completion are not claimed. Git is not
deliberately denied versioning, locks or a valid startup path. No generic superiority or
equivalent permission contract is inferred. Source revocation changes only the dedicated
synthetic Evidence's eligibility; business Claims and public user memory are untouched.

Public call timing is recorded individually in `mechanical-calls.jsonl`; file operations
have aggregate elapsed time. These are single observations, not comparable latency
benchmarks. Installation, migration, Git/MCP writes and reads are additional lifecycle
operations. Human time, infrastructure resource costs and GPU monetary costs were not
metered; they are not silently zero. No model constructed the seed, so its model-generation
cost is zero, while its human construction cost is unobserved. This is conditional seed
use, not autonomous save economics.
