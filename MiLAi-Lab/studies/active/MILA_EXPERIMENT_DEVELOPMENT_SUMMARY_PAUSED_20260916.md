# MiLAi 实验开发总结报告（暂停交付版）

## 1. 总结与当前决定

**已按用户指令暂停当前实验，并保留代码、结果、失败记录和未结算请求。** 本报告覆盖最初的 RWC v0.4 规划执行、后续 Adaptive Memory 首版，以及当前 ReasoningBank 迁移／多会话研究。前两阶段已经有界收敛；当前研究尚未完成。

截至北京时间 **2026-09-16 00:19:15**，实验驱动器、批次调度器、自动接续监视器和四个正在执行的 benchmark worker 均已暂停。00:27:34 的只读快照确认记录中的 11 个进程仍为同一进程且处于 `T`（停止）状态。共享模型及 embedding 服务保留。暂停后的工作仅为本地汇总和打包，没有新模型请求、业务动作、评分重跑或预算分配。

核心结论：

1. **工程链路已落地。** 原生 DB／OS／旅行环境、四种方法、固定银行迁移、在线流、成本账本、真实记忆输入、跨进程恢复及分析入口已有实现和验证。
2. **已有正式 DB 结果，尚无完整研究结论。** 四方法 F/O 主比较与正确历史参考共 820 项原生记录。MiLAi 对 RB 的正确率点估计均高 5 个百分点，区间尚未建立预设的有用收益；MiLAi 正确率低于 Native，TEST tokens 约为其 4 倍。
3. **修订机制的净收益未得到证明。** DB 的 200 项候选主任务没有自然来源回读或获准修订。实际记忆及采用备注进入 Actor 输入已经确认，但不能据此归因分数提升。
4. **旅行可执行性有所改善，质量仍弱。** v0.4 VALID 达到 55/58 人员终态，PS 1.72%、SPS 22.00%、SR 0；正式旅行 TEST 尚未开始。SUPPORT 中 OM、RB 已出现上下文容量失败。
5. **研究继续保持暂停。** 未启动项、失败后的覆盖恢复、贡献／资源比较和普通消费诊断均不自动接续。第二求解模型按用户要求暂缓；本报告不提出跨模型结论。

## 3. 已完成的实现与运行条件

### 3.1 方法和作用域

| 方法 | 具体实现 |
| --- | --- |
| Native | 沿用 benchmark 原生业务动作、交互终止和评分；旅行保留给定及累计计划 |
| OM | 同步 Observer／Reflector；12k／16k 阈值、recent 2、4k 来源页；保留当前原生交互历史 |
| RB | 按当前查询检索 top-1 历史任务的最多三条经验；独立自判与成功／失败提炼；保留原始 Markdown 逻辑条目 |
| MiLAi | RB 底座，加临时采用备注／Frame、按需来源回读及 Actor 明确请求后的旧经验修订 |
| 正确历史参考 | 上游回调筛选此前 CORRECT 且 COMPLETED 的历史；反馈条件不同，单独报告 |

候选采用阶段仅写临时工作判断。修改旧经验必须引用 Actor 实际看过的条目版本和真实业务反馈；不能把维护器自判当成原生 evaluator 反馈。只追加贡献对照已实现，沿用相同调用机会，但保留旧活动经验并追加建议。

- **F，固定银行迁移：** 每种记忆方法先用 SUPPORT 形成银行；每个 TEST 使用临时副本，测试后的提炼照常计费但不跨题提交。
- **O，在线流：** 每条流从空银行开始，仅继承本流此前完成任务；流间不共享，也不预装 SUPPORT 银行。
- **G，依赖旅行组：** 从固定支持银行复制，组内沿原生顺序处理人员；给定 base plan 不额外生成 Actor 答案，其记忆维护单独计费。

银行绑定 experiment、方法、模型、域、版本、协议、划分及 stream。公开 Working State 检查验证了实际 6 张卡片／2 个查询记录在新进程恢复后的精确银行及检索一致性；这是小载荷证明，不代表公开接口支持任意大银行。
