# Reserved64 native conditional evaluation

These six files are byte-identical public copies of the frozen entries used by
the local reserved-query64 protocol. The native candidate unions and masks come
from the existing `conditional_applicability` compiler; the primary comparison
uses the original preselected A1/A0 update2104 checkpoints, with the common
E1/update16 reference. No new fit or model selection is introduced.

All 64 shared-corpus query families and all 4,333 condition/candidate cells are
retained, including 267 unjudged cells. Native references stay offline. This
is a secondary conditional-label evaluation, not autonomous Host success,
FollowIR p-MRR, or independent document/Source confirmation.

The executable protocol and checkpoint copies remain in ignored local artifacts.
Its seven new code bindings and 1,135 inherited bindings were frozen before
protected semantic projection. All 18 copied checkpoint files were compared
over their complete bytes without hashes. The local freeze entry and full
literal code are also retained in the protocol artifact.

`bootstrap_reserved64_native_sdk_v1.py` imports the established CUDA-side
Transformers 4.52.3 and Tokenizers 0.21.4 before appending the existing HTTP/graph
dependency site. It uses existing installed packages, with no dependency upgrade.

All three fixed models have now completed all 4,333 first predictions each, full audits, native scoring, and independent score reconciliation. Original stage/launch artifacts remain unchanged.
Each fixed-model segment must be launched explicitly after the shared
model/HTTP worker lock, actual process exit, and cost gates pass; there is no
automatic next-model queue or first-outcome retry. The native prediction entry
opens only public state/questions, saves the raw first output, and never opens
gold or the operational ledger. Its parent bills whole child CPU and measured
parent CPU once after actual exit. Audit each full cohort before the next model;
offline scoring waits for all three full audits.
