## 本次保存的 r42 修复

`anchored_assertion_v3` 允许整条撤销省略／传 null 的 `changes`，公开含义为没有字段补丁。

并继承 r41 的提交前限制：仅重复旧支持区间不能撤销；不自动选择当前消息。

三类情况以及重开／显式恢复均有故障注入检查。旧 opt-in profile 保留原行为。

本次变化限于 Lab 的 opt-in 工具参数和失败交付协议，不涉及 Product Schema、认证、
Canonical 或默认配置。模型、thinking、容量、24 次生成、3 次读取和一次共享格式额度不变。
