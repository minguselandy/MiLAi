# V13 S4 条件采样对照预登记

本登记在 seed 11 的 6k/12k 方法对比出分之前完成。已执行工作仅使用 CPU 和已付 TRAIN 回执。后续收费额度在下文分别列出。

## 1. 已有重复测量

输入限定为 `warm-11/packs`、对应原始回执、只读 TRAIN 任务索引，以及冻结的 Host 成本单位。逐一要求相同原生组、任务、根、完整终端 wire（包括 seed）、确定性材料和输入 token 成本。MuSiQue 还要求同一真实 companion 的 provider ID 和账本槽。重复测量必须分别具有独立的 provider 响应 ID 和不重叠的实际收费槽；缓存引用、费用未知及目标缺失分别剔除。所有根均通过 TRAIN 角色联接。

协议内净效用为 `u = R − 0.05 × (immediate_cost + future_cost) / 1912`。相同根、终端包及确定性 token 成本下，其可变部分为 `R − 0.05 × output_tokens / 1912`。这一区分对根 47107 尤为重要，两条路径的已知即时成本分别为 838 和 105，最终输出分别为 76 和 94 tokens。只对 future_cost 作差会把第一步成本转移混入噪声。

## 2. 证据触发与共同协议

先闭合原定自然 DEV 队列上的 6k 机制对比和 12k 在线对比，记录 PQ-A 对 PQ-U 的配对原生组宏质量差、区间、缺测界及分来源表现。6k 检验在共同池与 π₀ 下的选样效果，12k 检验包含策略变化的完整流程。只有开发证据支持继续研究相应主张时才启用附加臂。一个检查点表现改善、另一个退化时，按各自问题解释。有限动作池训练分、四头分歧和单次点估计均不能替代独立复核。

条件臂共享本 seed 的同一批 2k warm 数据、同一份配对 warm 权重、四个 group-bootstrap 头、已冻结 Host 尺度与 λ。6k 使用同一 TRAIN 候选池、π₀、八根候选窗口、相同包生成器和包内比较。保留随机额度、零优先分回退、原生组剩余上限、完整续跑、companion、整包失败费用上界、动作可见性及优化曝光完全沿用主臂。选择分母 `d(P)` 采用本臂尚未见过的不同有效终端测量数，隐藏对臂的选样信息，含必要 companion。无新测量的包不产生正优先分。真实物理新请求与臂内曝光分别记账。6k 之后若检验在线效果，各臂冻结自己的 6k 策略并收集新的 before；先前 π₀ 标签仅保留其原始身份。

### High-uncertainty

优先分固定为包内预定义净优势的最大跨头 IQR 除以 `d(P)`。这与结构化分数共享所有实际动作对、四个头和费用，唯一区别是去掉与中位决策边际有关的扣减。若自然队列上两者相当，证据支持一般不确定性采样，结构化边际的附加贡献未成立。

### Generic EVSI-style

参照工作在固定局部高斯信念下，按观测能够消解的决策不确定性和现有边际计算二元 EVSI。它用训练执行校准噪声，显式建模共享参照，并在批内根据已排定的探测更新边际收益。原文使用归一化隐藏特征与正则化精度，按边际收益过滤探测成本，再在合格探测中作温度采样；批内先排定探测，再取执行返回。出处为 [UpliftMem §4.3、A.4、B.2](https://arxiv.org/html/2609.36805)。

项目适配预先规定如下。

1. 每个来源候选窗口内固定所有根的共同包比较族，每个无向比较仅计一次。不根据观察到的答案、分歧或 active 臂选过的根删改比较。令每个动作的均值是四头净效用均值，行向量 `Fᵢ` 是中心化四头分数除以 √3。潜在协方差取 `K = F Fᵀ`，允许不同候选间相关。该秩至多为三的近似来自共享模型，不能解释成校准过的后验。
2. 对待执行包的不同终端测量建立线性观测矩阵 `B`。同任务、同 wire、同 companion 的分支合并成一行。先按已知确定性成本平移到相同单位，再平均这些分支的预测形成该行。已兼容且已在本臂计入的返回不再提供额外观测。对臂已有的物理返回只在执行时去重。若 companion 已固定，使用条件噪声；若需要新 companion，使用同组联合噪声块。
3. 对比较向量 `h = eₐ − eᵦ`，取 `μ = hᵀ mean(u)`、`k = BKh`、`W = BKBᵀ + Ω`。用线性求解得到可消解方差 `s² = kᵀ W⁻¹ k`。当 s > 0，局部 EVSI 为 `s φ(|μ|/s) − |μ| Φ(−|μ|/s)`，其中 φ、Φ 为标准正态密度及分布函数；s = 0 时取零。以窗口中固定比较族的 EVSI 总增量除以 `d(P)` 得到整包优先分。保留分层随机槽，其余选最大分，同分采用共同随机规则。当前每次选择一个包，选择前冻结均值与协方差；若为了调度合并多个包，先对尚未返回的已选观测做高斯条件协方差更新，整批冻结后再执行。每次换模型后重算各窗口特征。
4. 净效用噪声 Ω 与潜在值协方差 K 分开。按来源和 HANDOFF/READ 估计重复执行的绝对净效用组内波动。HANDOFF 的绝对净效用保留模型预测值。使用绝对标签时没有公共无记忆减项，换为相对同一 HANDOFF 的差值时，使用相应差分矩阵变换噪声块。共享同一付费 wire 用同一观测。MuSiQue 的 pair 门控为非线性，不能直接套用相加的公共基线方差。每个新 companion 对应的跨动作协方差由下面的配对重复估计。数值预设为协方差向其对角收缩 1/2、特征值下限 10⁻⁶（净效用平方）。分辨率不足、地板生效与 0.5 倍/2 倍噪声的排序敏感性同时报告。相同头、候选、预算与确定性选择使该方法成为通用 EVSI-style 迁移对照；论文的完整系统另有训练、写入和可变批预算。

各检查点预先比较 PQ-A 减 High-uncertainty、PQ-A 减 Generic 的原生组三源宏质量差，6k 解释机制，12k 解释在线流程。报告按来源分层的配对原生组 bootstrap 95% 区间、同检查点两个对照的 Holm 校正结果和缺测界。净差为负时保留其方向，区间跨零时记为未分辨；肯定某个检查点的优势要求同方向的区间、校正检验和缺测界都支持。点估计相近不能据此作等价声明。此解释规则不约束是否显式选择后续复核。

若 PQ-A 无法在相同曝光的自然 DEV 上超过该对照，则撤回独立多粒度选样贡献。即便超过该对照，包结构本身仍须在相同规则下与非结构化可行动作对单独比较。各来源收益、开销、缺测界与跨采集 seed 结果单列。

## 3. 条件噪声补采及费用

High-uncertainty 不需要重复校准。准备运行 Generic EVSI-style 且当前 TRAIN 库存缺少每来源至少 8 个不同原生组的可用 Handoff 与 Read 重复或 MuSiQue 共享 companion 协方差时，才开校准。当前库存不满足这些条件。先用 TRAIN 原生组均匀抽取固定的 8 组/来源，冻结种子和合法动作后再看质量；把缺少合法不同 wire 的组记入抽样流程。每组在同一 before、冻结 π₀、相同 Reader 和预算下做两轮实际重复。每一轮的主动作请求独立提交，使用预先登记的独立重复种子；两轮分别记录底层 seed，其他协议相同。该额外测量估计对重复随机配置的敏感性，已有固定 seed 的 5 组仅作为对照，分别报告。若固定温度导致重复完全一致，也保留原始零估计以及显式方差地板。

- QASPER 与 Persona 各固定 HANDOFF 及一个合法读取，每来源 8 × 2 × 2 = 32 次，合计 64 次。
- MuSiQue 每组固定 HANDOFF 及两个不同对象的合法读取，独立运行这三个主分支与该轮共享的一个 companion。8 × (3 + 1) × 2 = 64 次。完整保存并离线交叉配对这两轮主成员与 companion 的返回。条件于每个 companion 比较主分支重复，联合噪声使用两轮各自的同组向量计算按组中心化协方差；交叉组合仍只有两轮原始执行。读动作作交换对称化，同一包存在更多读取时按 H/H、R/R、H/R 与不同 R/R 项扩展块，再作上述 PSD 收缩/投影。固定 companion 时使用条件估计并去掉其附加公共波动。
- 该校准单列成本科目，上限 128 次物理请求，并占用 EVSI 臂自己的 6k/12k 训练反馈额度。每个产生费用的失败消耗同一额度。未观测值保留 mask；有效组不足则记为估计不足。不同种子之间相互独立仍是一项模型假设。额外重试或扩样需单列新的实验额度和理由。

两条附加臂在主比较中各从共享 warm 的 2k 到达累计 6k/12k。High-uncertainty 从 2k 到 6k 可花 4,000 个普通包曝光。若 EVSI 校准消耗 c 次，则 EVSI 的该段为 c 次校准加 (4,000 − c) 个普通包曝光；普通包仍保留至少 1,000 个实测均匀曝光。两臂在 6k→12k 各再用 6,000。至 6k 合计新增上限 8,000，至 12k 合计新增上限 20,000，已含上述最多 128 次校准。所有普通包使用同一包空间、目标、每包优化曝光和拟合规则。校准耗去的可训练包数属于方法成本，原始校准标签仅用于噪声测量。若额外比较相同数量的普通包，需把该 EVSI 点标为 6k+c 或 12k+c，并单列这 c 次追加，不得用于等总费用主张。两臂两个检查点各用 150 题时，另有最多 600 个单次评估请求。独立采集种子复核另计，既有 72k 主训练矩阵不承担此项补采。当前 Generic EVSI 仅有预登记公式与辨识条件，尚无实际评估结果。

## 4. 独立采集复核入口

`tools/run_memory_control_v13_rounds.py --acquisition-repeat` 只支持采集 seed 29 或 47、拟合 seed 11、终点 12k。首个收费动作之前核对 seed 11 的两份真实 DEV 结算、同一自然队列、6k 共同池、各臂等额曝光、同一 S1 与 Host 尺度。调用该可选入口即选择复核；每次登记原始效应、区间、缺测界、来源分层及可选研究理由。两个检查点作用不同，入口保留正负方向和跨零区间。

每个种子自行采集 2k warm，PQ-U 与 PQ-A 从同一 paired warm 权重出发。2k→6k 各花 4k，沿用共同的冻结规则和 TRAIN 池；6k→12k 各花 6k，分别使用本臂 6k 策略。每个种子的臂内累计曝光为 24,000，独立物理新调用上限为 22,000。两个种子合计至多 48,000 臂内曝光、44,000 个新增训练请求。最多 1,200 个单次 DEV 评估请求单列。每个检查点在 `repeats/` 记录每臂曝光、各去重目录的已付/未知费用和物理账本区间；两个种子终态都出现后检查区间互斥并生成合计账。seed 11 的早期共同 warm 有 198 根在来源配额修订前完成，跨 seed 解释保留这项差异。

以下为条件命令。使用本研究实际的 S1 目录、冻结权重根和训练 Python 环境。从 MiLAi-Lab 执行，每个采集种子只运行一次，可用同一命令恢复未完成的部分。

```bash
R=/cra/milai-experiments/v13-qrag
PYTHONPATH=src python tools/run_memory_control_v13_rounds.py \
  --root "$R" --weights "$WEIGHTS" --s1 "$S1" --curve "$R/rosters/curve-2048.json" \
  --acquisition-repeat --acquisition-seed 29 --fit-seed 11 --until 12000 \
  --repeat-reason '填入当前开发证据及待复核的机制或在线主张'
```

另一个独立种子使用 47。高不确定性及 EVSI 费用按一次对照采集计算。当前独立种子入口只进行了临时文件与替代调度器的测试，验证了单个 warm、两臂不同的在线策略路径、组合计费和重复启动条件。实际训练/评估队列均未启动该入口。
