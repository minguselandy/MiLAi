# N2 前瞻形成与分段协议

本协议在任何 RFC 自然问题、答案或充分集合标注创建前冻结。32 个候选仍为单一技术标准来源家族的开发材料；不是已证明独立的 32 历史，不声称满足四层各 8 条。原始 104 份获取记录及被替换原件保留。

## 顺序与门禁修订

第 05/10 节要求真实 metadata 先于未来问题形成，但 T1 排在 T0/G1 后。因此只把 N3 的一次 query-free 形成子步骤前移到 N2：冻结输入、prompt、schema、失败政策，统一形成一次并封存，然后才允许 T0 问题/标注。G1 前不训练预测器、不分析 T1 信号、不调选源策略。若 G1 不成立，这次形成费用仍保留。不是借用免费 Writer；每份勘误的一次独立形成调用全部计入冷启动费用。

Writer 每次只看到一份已收到的公开勘误（含页面原文、纠正文和注释），没有未来问题、evaluator、后续勘误或推断的正确关系。完整 RFC 在档案和通用索引中保留；不为巨型 RFC 强塞上下文，也不声称已对所有原文语义形成 metadata。RFC 未抽取字段保持 unknown。形成输出只作可重建研究注释，不创建事实、VerifiedObjectRef、业务授权或持续世界状态。

## 原文视图与分段

RFC TXT 以 UTF-8 严格解码，保留原始换行及所有字符。勘误 HTML 使用页面中 RFC 标题开始至操作按钮之前的完整内容区域，移除标签并解码 HTML entities；保留 pre/code 内文本及顺序、元数据、旧文、纠正文、注释，记录原 HTML hash、选取区间、转换代码 hash 和派生文本 hash。该派生文本是归档 Source 的 body_text；所有后续 span 均相对此 body_text，不冒称解码后的字符区间等于 HTML 原件字节区间。

所有非空 body 使用同一 query-free 分段 v1：空行段落为优先边界，原顺序贪心合并，最多 384 个正文 tokens；超长段依次按整行、空白边界、必要时 Unicode 前缀拆分，精确 tokenizer 校验。无重叠、无去噪、无按问题裁文，拼接全部 span 必须逐字符还原 body。空串显式排除，不造内容。索引及标签/包装成本单列，实际 evidence budget 含包装和 metadata；384 不是完整证据集大小或效用保证。

## 公共关系、时间与相同信息

由页面公开 RFC 目标及 section 指针建立分支关联，逐项保留来源；同 RFC 多条勘误不按日期或 ID 伪造连续 supersedes。B1 的原文和更正分支、共同候选链扩展及 K32 容量遗漏在 T0 方法冻结时明确。B2 只用实际公开字段和冻结抽取；report/verification/publication/observed 时间均不能替代 valid_time。自然问题只有原文，不附 query_kind、gold mask、标准动作或 E*。

Writer 返回 subject/property/time/scope/exception/relation cues，全部只是抽取假说。每个 cue 必须有 body 中逐字 quote；自动校验最多证明 quote 来源，不能证明语义正确。缺失字段、形状错误、quote 不匹配、模型错误保留原始返回并标 unknown，不重试、不人工补齐。open_set 固定保留。ID/文件名/顺序不是语义特征。原始模型返回不进入事实 bank。

执行 validator 与输入一并冻结；任一 schema/quote 校验不通过，整份抽取均使用空字段、全部维度 unresolved、open_set=true 回退，原输出仍保留。重复 quote 保存所有匹配 span 并标 ambiguous_location，不默认第一次匹配是所指旧文或纠正文。合法形状不是语义通过。metadata 只绑定其实际输入勘误，不广播为整份 RFC/所有 passage 的已知字段；选择器若读取 source 级 metadata，所有臂共享并计量其处理与材料费用。

## 形成调用与失败政策

Root 使用既有 Qwen 服务、统一连续账本和串行 HTTP owner。每份被准入候选的勘误最多一次调用，0 embedding、0 查询规划、0 自动重试；输出上限沿用 4096。预先校验完整请求容量；超长输入记为未形成，不按未来问题裁切。所有请求保存持久准入和真实 wire/usage，未知请求保守计费且不得补槽。代码/配置/输入/账本在开始前冻结。形成终态之后单独冻结实际 metadata 和全体失败，才开放 query 创建。

## 后续标注边界

允许 erratum 本身含旧文/纠正文/解释而独立充分，不能强制每题都要 RFC+erratum。互补集合必须由约束实证；不足档案的 coverage 是 N/A。报告四类问题可解性、允许部分答案、剩余不确定性与最小充分集合族。来源语义共享依赖、模板和真实关系审计独立进行；有相同父规范不自动意味着同一更正历史，也不能忽略实质派生关系。

G1 只认“消歧证据存在，同预算完整链/时态检索仍有可重复缺口”。普通长文检索失败、技术推理错误、已送达证据的 Reader 误读、显式勘误已解除歧义，都不能单独支持关系歧义选源的新增贡献。四层配额不足如实报告，不补造自然样本。第二位工程代理的协议审查不是独立人类语义标注或第二模型家族。

形成完成只是开放问题创作的一个前提。共同候选、链分支扩展、K32 截断、包装及 B1/B2/B3 规则也须在问题创作前冻结；B4 主定义沿用已经锁定的 cost-normalized EC²-style edge-cut approximation，未就绪不作优势比较。
