# 旧64保留query：三套固定模型的原生条件标签结果

三模型共12999个原生首输出已全部完成、整进程计量并通过全量审计；逐格原始输入、
首输出、标签掩码及20,000次配对区间已独立复算。预定主比较A1−A0为−5.37个百分点，
95%区间[−7.76，−3.16]，不支持原生负例覆盖改进相对legacy组成的优势。两训练臂
均高于既定初始参考，但这不是Host任务成功或独立文档泛化，A20k/J等停止决定保持。

## 冻结合同与分母

模型为原开发阶段已选定的E1/u16、A0/u2104、A1/u2104；7新＋1135既有代码绑定、
原始输入投影与评分在保留语义投影前冻结。18个权重文件共2034760045字节复制并
逐字节核对。每模型同一4333格全量预测，包括267个unjudged；127条原始UTF-8行、
全部title/text/query/purpose、原生4066 known与267 unknown掩码均完整相同。
这64组是共享语料query家族，不是64个独立文档或Source历史，也不加入256论文确认分母。

预定主指标先在每族每标签内部平均，再平均两标签和64族。全部64族均有两标签支持，
没有丢族、换指标或改未知标签。已知标签为127个satisfies、3939个does_not_satisfy；
普通hard-negative membership为弱原生证据，非独立人工事实判断。
