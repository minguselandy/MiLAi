## 实际证据与失败边界

generated-2048 的 129 次 HTTP 包含 120 次 Host thinking=True 和 9 次 View builder thinking=False，均与冻结配置及实际请求一致；新增未知用量为 0。21 次失败包括 20 次截断和 1 次格式错误，全部保留首次结果，没有修复答案或从推理文本提取答案。

其 9 份实际收到的 View 材料全部完成语义源审，共 37 次实际输入出现、204 个来源别名绑定；另有 185 个原文范围逐值绑定。历史输入中的重复材料不算新增调用，也不算 USE_VIEW 命中。全程实际执行 9 次 REFRESH_VIEW、28 次 SEARCH、96 次 READ 和 28 次 HANDOFF；USE_VIEW 为 0。40 次当前工具返回均进入对应实际 Host 输入。

已核实的机制包括：

- 生成节点把朋友适应新工作的主体改成用户，最终回答重复了错误；实际生成请求中的原始主体正确。
- 旧 Host 的“没有待回复改期”被当作当前事实，而最终用户拒绝改期的来源没有进入生成器。最终文字碰巧符合事实也不能补足这条证据链。
- 用户肯定报告腌萝卜很好吃，该报告已进入生成器；生成节点却从较早的助手问句得到“没有尝试”，后续回答沿用错误否定。
- 原话请求下，部分 Host 将生成节点的第三人称改写或助手复述当作用户原话。
- 部分预算检索只返回旧问题、旧回答或历史部分预算，缺失开支被算作 0，或历史小计被当作扣除全部开支后的余额。

以上为选取的已暴露开发案例，不能当作总体发生率或未执行反事实的结果。View 忠实性、当前任务材料充分性和最终答案质量分别评分；实际正确原文未交付时，不能拿它替错误 View 补证据。
