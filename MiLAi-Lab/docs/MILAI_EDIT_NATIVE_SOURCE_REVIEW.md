# 原生更新切片的来源审查

固定切片包含 32 个参考更新条目，来自四个开发用户、十二个实际会话。多个条目共享同一次摄入和编辑，统计按用户聚类，不能称 32 条独立历史。词汇筛选标准见分析规范；筛选发生在最初三个格式回执之后，未用比较性机制效果选例。来源审查在首个 B0 臂运行期间完成。

原对话与官方参考保留在忽略的 `artifacts/milai-edit/selection/native-updates-v1.json`；逐项来源判定在同目录 `native-update-source-review-v1.json`。这是 Root 阅读原对话后的评价标注，不是独立人工团队或独立模型家族审查。它们不进入 Writer/Editor，也不作为理想旧记忆初始化。所有臂的机制分析必须使用该臂真实形成的 before/after 状态，并报告初始目标缺失。

本切片确认了普通变化、语义补充、取消、持续不确定和仅换说法的重申。没有确认范围化例外、明确的条件保留更正或历史勘误。Donald 的“以前喜欢烤三文鱼、现在失去兴趣”是当前偏好取消和历史重述，不证明先前记忆为假。此缺项只描述所选切片，不能推断全数据没有这些案例；受控补充须单列。

官方更新参考与实际来源存在需要单列的差别：

- Johnson 的新收入 4500 USD、储蓄 14000 USD 只出现在 assistant 断言中；user 只报告增长。这不证明数字为假，但不能将其说成 user 自己确认的金额。
- Sarah 的 user 明确说月收入增加到 18000 USD，assistant 多次断言从 18000 增加到 20000 USD；官方参考采用 20000。官方打分原样保留，来源和角色一致性另列，不静默修正参考。
- Donald 的退休对话没有说明当前总收入为零。退休本身不排除养老金或其他收入。
- Sarah 的饮食变化由 assistant 补入，user 确认的是运动与正念；Johnson 的拟议合作与扩张也不能自动写成已经完成并导致收入增长。

评价规则区分 user 的个人事实、assistant 的断言/建议和实际工具观察。不确定信息保留适当归因与不确定性；缺乏支持不等于自动推出否定。NeverWrite 可能通过重申类条目，却不能完成真正新变化；RetainAll 可能保留旧事实，却留下当前冲突。二者分别报告有效更正、非目标语义、无依据新增和后续 QA，不能仅凭保留率得出成功。
