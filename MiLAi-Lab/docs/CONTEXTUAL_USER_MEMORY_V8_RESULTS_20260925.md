## 已交付

- 最终回复与维护决定共享 Host 循环；saved 必须对应真实提交的当前持久记录及实际来源，
  无变化允许零写入，未完成保留 pending 并可同轮恢复。真实业务 success／failure／unknown 分开记录。
- 单写者本地持久入口支持所有者／模型／配置／协议校验、原子落盘、新进程重开、实际会话交付恢复、
  完成轮次去重。业务 intent 与原始结果分别保存；未知执行禁止自动重放，核对结果作为新证据。
- 支持准确版本上的唯一匹配 content_patch，保留其他正文并检查完整来源与 CAS；
  中文全文补齐汉字与相邻双字词项，保留原全文／向量融合排序。
- 普通来源关联直接引用它的当前解释及历史解释的当前修订，包含未修订的第一版卡。
  时间截断、retired、预算不足时待展开及真实范围仍受约束，不自动合并或改写事实。
- 每个新轮次在接收输入前以原 query／4 项／6000 bytes 预取；恢复与完成重放跳过。
  相同结果仅复用仍在实际 transcript 中的交付，缓存命中及异常后重新收紧真实可见性。
- memory_read 的 include_sources=true（含默认值）真实交付请求的来源正文，false 保留链接；
  独立参数不会展开其他可选邻居关系。正文缺失错误明确标出字段和句柄。
- 修复无材料拒绝回执的持久化崩溃、退出时覆盖原异常，以及 MERIT 错误关闭未完成会话的问题。
  非 complete 轮次立即保留未评分中断制品和实际活动状态，不继续下一消息；pending 按真实字段汇总。
- 默认仍为普通记忆，State 可选。同一 Qwen Host 显式启用推理，请求、容量计数与身份一致；
  4096 输出 tokens 包含推理和动作，截断不执行。累计请求／tokens／验证次数上限为 null，连续计费不清零。
