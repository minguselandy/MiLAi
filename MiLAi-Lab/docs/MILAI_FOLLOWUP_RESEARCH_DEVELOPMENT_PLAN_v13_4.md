## 02  研究问题与查询语义

*不要把所有更正都视为同一种更新*

旧消息“用 A”，新消息“不是 A，是 B”可能表示后来改变、追溯纠正、局部覆盖，也可能同时包含时间变化和范围收缩。保留未决维度，而不是强迫“变化／纠错／局部”三选一。明确的 B 应正常使用；仅对未被证据确定的历史或范围保持不确定。

| 查询种类（仅用于说明） | 所需语义 | 正确的研究问题 |
| --- | --- | --- |
| 当前明确对象现在用什么 | 各合理解释可能都支持 B | 额外取证是否无益，能否保持正常效用？ |
| 我之前告诉过你什么 | 陈述历史：当时说过 A | 完整更正链是否已经足够？ |
| 据现在更正，过去实际适用什么 | 追溯真值／规则有效期 | 是否需要区分“后来变化”和“之前记错”？ |
| 其他项目、时间或对象呢 | 范围、例外与适用边界 | 是否有相应证据；缺少证据时是否避免泛化？ |

以上 query_kind 是 evaluator 的标注维度，不得作为隐藏标签送给运行时。模型只得到自然问题；诊断中的人工 query mask 必须单列 oracle 条件。

### 三个先后检验的假设

H1：在当前问题确有关系歧义、且消歧证据实际存在时，完整更正链／时态检索仍有可重复的预算内缺口。H2：真实、query-free 形成的元数据，在未见来源上比相关性与“缺什么找什么”更能定位必要证据。H3：相同信息和成本条件下，预测器或选择策略至少有一个提供独立净收益。

### 问题的最低形式化

```text
A(h, q) = 解释 h 对问题 q 导出的答案约束
h_i ~q h_j  当且仅当 A(h_i, q) = A(h_j, q)
目标：优先寻找能区分不同答案约束的来源，而非消除一切不确定性。
```

A、解释集合及其覆盖并非天然已知；不得让免费 LLM 先对所有解释回答，再称“无额外调用”。开放域答案比较首先由标注侧检验；运行时从保守的维度相关性代理开始。候选一致不证明候选之外不存在真解释。[L2,L3]


## 03  相关工作与创新边界

*把贡献限定在真实缺口*

| 一手近邻 | 已有覆盖 | 本版必须超过的解释 |
| --- | --- | --- |
| Katsuno–Mendelzon [L1] | 区分世界变化的 update 与知识纠正的 revision | “后来改变／过去记错”不是新形式化 |
| EC²／HEC [L2,L3] | 等价类／决策区域相关的成本敏感主动观测 | 多解释＋主动取证本身不新 |
| BeliefMem [L4] | 多候选、Noisy-OR、Merge 旧版本及联合呈现 | 不能把它弱化成不保留历史的单候选方法 |
| Zep／TSM [L5,L6] | 时态关系、语义时间与持续状态 | 仅增加时间／范围字段不构成独立贡献 |
| LongMemEval [L7] | 索引／检索／阅读分解，时间感知查询扩展 | 时间扩展与完整历史应成为强对照 |
| STALE [L8] | 隐式冲突、前提抵抗和状态适应 | 未见新反证不是未被研究的空白 |
| 自调整计算 [L9] | 依赖与变化传播 | 备选线必须证明自然语言不确定性下的净价值 |

### 可以争取的贡献

一个带真实元数据缺失／错误的消歧证据评测协议；一个不增加独立查询规划调用的证据价值预测方法；或一个证明通用策略在何种条件下有效／失败的应用研究。是否足以形成方法论文，由独立对照决定，不预先承诺录用或“新算法已找到”。

### 概率与保证

BeliefMem 的候选分数不是互斥解释上的归一化联合后验。不得直接归一化后套用 EC² 理论；需要显式说明假设覆盖、先验、观测结果模型、噪声和相关性。使用学习得到的近似结果模型时，标记为 EC²-style approximation，不继承原文近似最优保证。[L2–L4]

> 创新归因只允许二选一先验证：固定选择器，比较结果／价值预测器；或固定预测器，比较选择器。更准确的元数据和更好的策略不能同时只给 Ours，再把差异归因于策略。


## 04  最小数据合同与信息权限

*事实、解释、索引分离*

复用真实 SourceEvent、record/revision 和既有索引。只增加可重建的研究注释，不创建新的长期真相库。不确定解释标为研究假设；不得取得 VerifiedObjectRef、授权或当前世界状态的资格。[U0,R4]

| 拟新增数据合同 | 最小内容 | 不可越过的边界 |
| --- | --- | --- |
| CorrectionRelation | 旧记录句柄、新 Source、显式变化、未决维度、原文 span | 不得强制三选一；无法枚举完整时保留 open_set |
| EvidenceMetadata | Source 身份、主体／属性、时间／范围线索、线索来源 | unknown／conflict 保留；不是正文语义已证实 |
| QueryView | 当前自然问题、合法截止时间、预测的维度 mask | 不得接收 gold query_kind、答案或标准动作 |
| SelectionPlan | 候选 ID、分数、成本、选中项与遗漏项、策略版本 | 不得先解析未选原文；无免费人工补证 |
| DeliveryReceipt | 实际送达 span/版本、token、快照与 read 事件 | 非空、选中、完整送达、正确消费分开计量 |

### 两种时间，不互相填补

observed_at 表示真实接收／观察时间；valid_time 表示来源明确支持的有效时间区间。没有有效时间锚点就记录 unknown，不能用运行日期填补。“现在已知过去是 B”和“过去曾记录 A”需要同时可表达。[L1,L5,L6]

### 来源与 span

原文 span 采用 Unicode codepoint 的 [start,end) 半开区间并绑定原文 hash，机械核对只能证明片段来自哪里。缺失、歧义、抽取错误与公开工具字面观察分开记录，不给自然语言抽取结果增加“已验证真值”标签。

候选最多 K=32 是初始开发容量建议；局部解释仅用于诊断时上限 H=4，并保留未枚举标记。两者都是待 pilot 冻结的工程参数，不是保证。所有方法共享同一候选池；池外遗漏另外报告。


## 05  写入与查询的最小实现

*先做一次性选择，不做自适应大循环*

```text
真实历史事件
  → 原有形成边界：附加 query-free 元数据／未决关系
  → 固定、可重建索引
当前自然问题
  → 共同普通候选检索
  → 便宜的维度相关性／证据价值预测
  → 一次性预算内选源
  → 精确读取选中原文 → 共同 Reader → 原始答案
```

### 写入时的约束

元数据在相应事件可见之后、未来测试问题出现之前生成。可在已有 writer 调用中增加输出，但新增 token、存储、embedding 和解析失败全部计费；已有方案无 writer 时，不能把新形成调用说成免费。不从 Reader 答复或检索注入文本再提取新的用户事实。

### 查询相关性不是免费 oracle

第一阶段比较两种共同 profile：Q0 保守使用所有尚未确定维度；Q1 使用仅在开发来源训练并冻结的轻量 query head。Q1 不调用新 LLM，特征来自自然问题及元数据；其分类误差单列。人工 mask 只在诊断使用。所有选择器使用相同 Q0／Q1。

### 不确定时如何退化

元数据缺失、形状无效或 query head 无法判断时，回退到共同的完整更正链／普通相关性排序，并报告触发原因。回退不是“检测到没必要检索”的语义证明，不能把 unknown 当作不相关。明确当前要求仍正常处理；无法确定的历史或范围采用局部保留、澄清或合理拒答。

### 调用合同

主轨道新增独立查询规划 LLM 调用为 0，最终 Reader 一次。取证是一次性选源，不宣传自适应主动学习。若后续使用多轮“读取—解释—再选择”，另开 adaptive 轨道，所有中间解释、工具读取和最终回答共用完整预算。


## 06  证据价值预测与选择器

*先测信号，再加复杂度*

先采用不训练的缺失维度定向检索作为强简单方法；若出现预测空间，再试一个正则化线性或排序模型。首批限制在不超过 12 个冻结特征，不引入新的语言模型、图网络或 RL。小样本交叉验证只用于开发，不作泛化结论。

| 可用特征 | 明确限制 |
| --- | --- |
| 共同 BM25／dense 分数；真实选源成本 | 底层索引成本与 query embedding 全部计量 |
| 主体／属性匹配、已知时间区间关系 | 来自模型的字段必须保留不确定；不据此证明无关 |
| 时间／范围／例外线索的存在与抽取状态 | “出现日期”不等于“存在生效日期” |
| 实际版本邻接、来源角色、来源重复标记 | ID 编号、模板名、文件顺序和 gold 类型不能作特征 |

```text
score(e,q) = Σ[d∈D(q)] w_d(q) · r̂(d,z_e,C_q) / c(e)
D(q)：预测的相关未决维度；C_q：所有方法共有的已读基础材料。
r̂：对该维度提供消歧帮助的预测，不是事实真实性或最终解答保证。
```

该公式是成本敏感启发式，不宣称算法创新或近似最优。单份来源“有帮助”不等于充分证据；多来源互补与重复支持必须单列。首版先使用共同去重规则；只有单源预测证明有信号时，才增加集合互补特征，避免全历史 pairwise LLM 判断。

### 通用主动取证对照如何实现

合成小型可枚举问题先按原文验证 EC² 的边切减／成本与 HEC 的区域设定。自然语言轨道使用共享的近似结果模型与解释集合；缺失观测概率就标为不可运行或近似条件，不用 gold 补齐。静态首步与多轮自适应分表，不能让对照多次付费读正文而 Ours 免费读。[L2,L3]

> 同样元数据、正文不可见而互换的配对反例必须保留：若两个来源的可见特征完全一样，选择器无法凭空知道哪个正文含关键生效时间。性能上界由信息决定，不由评分公式决定。


## 07  最小基础修复与继承关系

*支持研究，不再扩大平台*

先修复实验入口的实际证据交付、快照身份和只读隔离。不把完整 EDM／CEP 的产品化作为 T0/T1 的前置条件；也不因此宣布其余旧验收已通过。[R3,R4]

| 问题／旧能力 | 本版动作 | 验收或边界 |
| --- | --- | --- |
| 正文被 metadata 挤掉 | 建立共同的内容优先小适配层；保留原候选顺序做对照 | 实际 HTTP 含完整证据；未放入明确记遗漏 |
| 查询后不必要写回 | 只读研究冻结 bank，方法均禁止事实 mutation | 查询前后事实版本／来源不变；日志新增单列 |
| Source 与版本句柄 | 复用现有 exact lookup／candidate／selected_snapshot | 测试 owner、版本、hash、重启和失效；不放宽 guard |
| 稀疏更新与事件消费 | 保留 v13.3 W2 为集成前工作，不在本线重复实现整套 | 空改动 no-op、真正更正不漏、scope 保留以后实测 |
| 保存／恢复 | 复用观察及真实业务 journal；区分已捕获和语义已提交 | 高风险动作不由解释假设授权；unknown 先查询 |

### 两条独立准入线

G0-Read：无业务副作用、冻结来源、实际材料可见、版本可追溯、成本可记录后，允许只读机制试验。G0-Integrate：新增写入或跨会话动作必须先补原正常 24 检查及保存、来源支持、范围和恢复门槛。两者不是彼此替代的通过标准。

### 不新增的基础设施

不新增常驻审稿／纠错代理、第二套真相数据库、跨域巨大 ontology、自动业务重试、隐式分页补读或最终答案重写。研究记录和索引可重建，运行原语继续由原模块维护。配置变化必须逐项写入 manifest，不能把“文件存在”当作“实验已启用”。


## 08  Baseline 与公平比较

*系统表和机制表分开*

| 正式机制主臂 | 实现定义 | 排除什么解释 |
| --- | --- | --- |
| B1 Chain-RAG | 相同普通检索＋原始更正链；完整证据包装 | 只是旧正文没有读到 |
| B2 Temporal-RAG | 同候选上使用可见时态／范围字段；保留观察与有效时间区别 | 普通时间检索已足够 |
| B3 Slot-Retrieve | 按共同预测的缺失维度选来源，不做复杂假设后验 | “缺什么找什么”已足够 |
| B4 Generic-Active | 共享解释／预测器／成本的通用 EC²-style 或信息增益实现 | 通用决策导向策略已足够 |
| M Candidate | 本次待验证的价值预测／选择组合 | 是否存在独立净收益 |

B4 必须在 N2 准入前锁定一个主实现，不在看到结果后挑选弱版本。不能准确复现原理论条件时，名称与报告显式加 approximation。B4 尚未就绪时可以继续机械验证，但不能声称优于通用主动取证。

### 必要的外部近邻

BeliefMem 用于多候选与历史近邻；Zep／Graphiti 或 TSM 至少选一个用于时态近邻。核对实际代码、依赖、提示、后台调用和版本后先跑小切片。只能实现自建时态 baseline 时，命名 Temporal-RAG，不冒称原系统复现。暂未核实可接入性是缺口，不是可省略最近邻的效果证据。[L4–L6]

### 共同条件与诊断条件

机制表共享 history、relation、metadata、candidate IDs、query head、来源权限、Reader、材料预算、tokenizer、附加读取与成本。系统表允许原生表示差异，但报告完整形成费用。FullArchive 仅为充分材料诊断；随机、metadata-shuffle、oracle metadata／oracle解释均单列，不进入可部署方法成绩。

> 同一组更正解释都能用于 B3/B4/M。若贡献来自新元数据，固定 selector 比较；若贡献来自 selector，固定 metadata／predictor 比较。最强简单对照不能只放附录。


## 09  T0：问题与证据可解性审计

*先判断有没有必要开发*

建议以 32 个独立开发历史为第一批预算起点，每段历史设计 4 类自然查询，共 128 个 query。32 不是统计功效保证。既有 R9 用作回归例，不计入新来源；从真实公开历史派生时应保留原文并审计许可、重复和曝光。

| 历史类型 | 建议数量 | 期待行为 |
| --- | --- | --- |
| 明确更正／歧义不影响答案 | 8 | 直接回答，不用多读获得虚假收益 |
| 存在单份消歧证据 | 8 | 找到有效期、对象或范围的真实依据 |
| 需要互补证据集合 | 8 | 组合来源；相关来源不等于充分证据 |
| 全部已知历史仍不充分 | 8 | 不补造世界真值；区分陈述回放与事实推断 |

### 执行与标注

先标注查询可解性、兼容解释、关键约束、允许回答与至少一个最小充分证据集合。对不可解问题不强造单一答案。标注者可看完整历史；运行时只看协议允许的材料。两位独立标注者优先复核可解性和证据集合；缺少第二人时标为单人开发审查。

用 Chain-RAG 和 Temporal-RAG 运行相同预算，建议 2048 evidence tokens；如加入 FullArchive，则另算最多 128 次 Reader，明确其信息与成本不相等。短历史所有证据能放入时保留这个控制，不人为塞随机噪声使基线失败。

### 输出与决定

输出逐历史的最早断点：档案缺证、候选漏证、包装漏证、证据解释错误、关系假设漏项。只有发现“证据存在、同预算简单方法仍有缺口”才进入复杂方法 pilot。32 例不足以确认缺口分布时可以扩大独立审计样本，但不按 Ours 胜负筛题。

> 若完整更正链已解决大多数目标问题，本阶段的正确结果是采用简单修复；不是继续强造多假设任务。不得用这一批已曝光材料宣称正式泛化。


## 10  T1：真实元数据的信息量试验

*这是主线的关键去留点*

先不跑完整 Agent。对 T0 开发历史执行一次 query-free 元数据形成并冻结其身份；同一 writer 输入截止于事件边界，不含未来问题、gold 或人工消歧标签。所有 query 派生自历史之后，训练／验证仍以历史或模板成组划分。

| 对照条件 | 用途 |
| --- | --- |
| 相关性／缺失维度 baseline | 先测低成本规则能达到什么程度 |
| 实际 writer 元数据＋线性预测器 | 测自然抽取噪声下的信号，不只测理想字段 |
| 保持边际分布的 metadata shuffle | 检验信号是否真实依赖元数据，而非长度／ID |
| oracle metadata／query mask | 诊断抽取与关系识别的上界，不作主成绩 |
| 同元数据、互换正文反例 | 暴露信息不可识别区域，不强行宣称可消歧 |
| 互补／重复证据子集 | 单份“有帮助”与集合充分性分开检验 |

### 标注目标

对每个 query，在共同已读材料 C 下标注来源属于直接消歧、部分帮助、无关、误导或重复。再标注最小充分集合族 E*(q)，允许多种等价证据组合。集合标签不足时报告 unknown，不把单源分数总和当作语义充分性。

### 如何避免过拟合

不把题型、模板 ID、文件名或未来时间作为特征；参数选择采用按来源组的交叉验证，所有变体同组。关系抽取和 query head 的错误单列；不得先看测试 gold 再决定哪些维度重要。候选预算对比 512／1024／2048，主预算在 pilot 前冻结。

### 输出与通过条件

输出证据覆盖—预算曲线、分维度预测质量、候选外漏失、元数据费用和失败类型。先冻结一个务实 pilot 目标，例如相对 B3 的充分证据覆盖提高至少 5 个百分点；这是设计目标而非已有结果。真实元数据无信号但 oracle 有信号时，最多两轮开发内抽取修订；仍无效就 Simplify／Stop。


## 11  T2／T3：端到端与泛化

*先小 pilot，再冻结正式证据*

T1 出现可信信号后，使用 24 个未参与 T0/T1 的历史做 T2 pilot。每历史 4 query、5 主臂，计划 480 个 Reader 结果。pilot 用于估计成本、场景间方差和功效，属于开发数据；不能再回收为独立测试。

| 批次 | 规划规模 | 条件与声明 |
| --- | --- | --- |
| T2 新 pilot | 24 历史 × 4 query × 5 方法 = 480 | 一个模型家族、一个主预算；冻结方法前可开发 |
| T3 正式起点 | 96 历史 × 4 query × 5 方法 = 1920 | 规模需按 pilot 重定并事前冻结；非功效保证 |
| 第二家族确认 | 24 历史 × 4 query × 3 方法 = 288 | M、B3、B4；重新形成与只换 Reader 分开 |
| 公开迁移 | LongMemEval／STALE 合格来源切片 | 数量由许可、曝光和任务适配审计决定 |

### 正式验证的主张

主张仅限相同候选信息与预算内的查询证据选择；同时评估直接回答、历史陈述回放、追溯适用和跨范围问题。无证据案例的合理不确定性单列。首篇论文不把只读问答收益扩展为业务恢复、任意权限或通用生命周期可靠性。

### 公开任务如何使用

LongMemEval 包含更新、时间和拒答能力；STALE 包含隐式冲突、前提抵抗与状态适应。它们可作外部锚点，但不预设每一题都是本版的关系歧义任务。使用官方 scorer 的结果与新增消歧标注分表，保留原始问题、来源和版本。[L7,L8]

### 真正的泛化

按原始历史／模板划分，不靠换 UUID、同义改写或增加 seed 制造独立样本。至少保留一种未见关系组合或独立工作流；跨语言变体与原版同组。第二家族不存在时不伪造服务，不把开发评审模型名称当作实验家族；相关结论维持 NOT_VERIFIED。


## 12  数据、标注与曝光控制

*先分组，再读取测试内容*

### 三个物理隔离的输入视图

| 视图 | 允许包含 | 禁止包含 |
| --- | --- | --- |
| WriterView | 截止当时的真实历史、原记忆、公开合同 | 后续问题、标准答案、未来回执 |
| SelectorView | 当前问题、已形成元数据、共同候选及成本 | 未选原文的语义结果、gold关系／证据标签 |
| EvaluatorView | 原始历史、query标注、充分集合、评分规则 | 不可被 writer/selector/host 导入 |

允许原文由通用索引检索，但必须声明底层特征：例如 BM25/dense 本来使用了全文构建索引，不应说系统“完全未接触正文”。关键限制是选择时不能额外语义解析全部候选正文却不计费。

### 划分规则

以 source_id、完整历史 hash、模板族及已知派生关系建立联合组。旧 R9／autoresearch 示例、写过提示或评分的样本全部计为开发。预留不等于已泄漏，但重新分配必须有未读取／未用输出的审计依据与事前修订；不删除旧曝光记录。

### 标注与证据不足

每条 query 保存答案模式、允许的部分答案、剩余不确定性及其理由；对多来源任务保存充分集合而非唯一“正确文档”。“完整档案不足”仅是给定档案与截止时间下的判断，不声称世界上不存在信息。合成的隐藏真值若无法从允许材料推得，不进入强制回答分数。

### 原始自然历史与构造诊断分开

优先保留真实公开更正；不足部分用明确标记的研究诊断补充，保持相似主题但有真实约束差异，不加随机噪声。反事实交换正文、删掉关键日期、加入重复证据属于诊断，不用于估计自然发生率。不得让 Ours 的表现决定样本保留。

> 不使用新盲池来修 prompts。标注、训练、开发选择、正式评分各自保存读取记录；正式结果揭示后，只允许执行预注册分析，不继续修改方法后复用同一“测试集”。


## 13  指标、统计与费用

*不把少读或多拒答当收益*

| 指标 | 定义与分母 |
| --- | --- |
| 充分证据覆盖 | 可解 query 中，实际送达材料是否包含 E*(q) 中任一完整集合；不可解为 N/A |
| 候选池覆盖／送达率 | 先测必要证据是否在候选池，再测选中与完整送达；不混成检索准确率 |
| 查询效用 | 分别报当前、陈述历史、追溯适用、跨范围；保留部分正确和 unknown |
| 无依据确定性 | 档案不足或证据不支持时给出确定答案的比例；同时报可解题过度拒答 |
| 假设／关系覆盖 | 标注兼容解释被保留比例、未枚举标记；不把候选一致当真值保证 |
| 维护终态损伤 | 集成阶段查询前后事实／范围／支持关系的无依据变化；只读阶段应无变化 |
| 完整成本与延迟 | 形成、metadata、embedding、选择、读取、Reader、重试、维护均计；Judge另列 |

```text
coverage(q,S) = 1{存在 E∈E*(q)，使 E 包含于实际送达的 S}
C_total = C_ingest + C_metadata + C_index + C_select + C_read + C_answer + C_retry
Δutility = paired_mean(utility_M − utility_baseline)
```

覆盖是证据指标，不证明 Reader 正确消费。对来源互补任务应计算集合覆盖；对无解任务不填 0 或 1。效用采用预注册的任务评分，不把不同任务未经定义合成总准确率。

### 统计设计

主比较为 M 对 B3、M 对 B4；按来源历史聚类配对 bootstrap，建议 10,000 次重采样，事前定义多重比较校正。跨语言、同模板和同历史多个问题留在同 cluster；seed 是重复测量。pilot 后、揭示正式结果前确定样本量与非劣界。

可将明确可答子集的效用非劣界定为 −5 个百分点作为待冻结目标；必须由置信区间支持，不用“不显著”代替非劣。样本不足时如实报告不确定。费用耗尽、提供方故障、未运行与语义失败分别保留，完整计划分母不可删除。

## 15  验收、预算与迭代限制

*所有门槛在看正式结果前冻结*

| 门禁 | 要求 | 不通过时 |
| --- | --- | --- |
| G0 研究可运行 | 权限／cutoff隔离、实际正文送达、真实成本、只读版本不变 | 修入口；不使用模型质量掩盖泄漏 |
| G1 问题成立 | 证据存在且简单完整链／时态方案有预算内缺口 | 采用简单方案，收缩研究问题 |
| G2 元数据有信号 | 真实元数据超过 B3／shuffle；oracle 与真实差异可解释 | 最多两轮开发抽取修订；仍无信号停止复杂选择 |
| G3 方法独立贡献 | 同信息 B4 对照成立；预测器／selector 至少一个独立有益 | 标记等效／应用组合，不宣称新算法 |
| G4 可报告研究 | 正式配对区间、效用／确定性／成本、来源与外部限制齐全 | 补独立证据或缩小主张，不重标旧开发为测试 |

### 预算策略

主 evidence budget 建议先定 2048 tokens；512／1024 为成本曲线，不能从结果挑主预算。检索候选 32、解释上限 4 都需 pilot 前冻结；所有方法获得相同实际约束。写入 metadata 增加的 token 及形成时间必须计入冷启动与生命周期费用。

延迟报告选择器 CPU、I/O、首次回答及完整结束时间；缓存命中率和预热条件分开。没有实际价格／GPU计时就不换算美元或GPU小时。借用现有 writer 不等于零额外成本；读取全部文档再分类属于另一个有成本的 baseline。

### 迭代上限与错误处置

每个核心假设最多两轮已曝光开发修订；每轮预写最早断点、竞争解释、一个最小区分实验和停止条件。接口错误与自然语义失败分开；未知请求不退款或复用槽位。禁止用重试挑最好答案，禁止评测后修答案。

本版只读研究不存在承诺收益的固定百分比。G2 可用预先约定的 5pp 覆盖差作进入 pilot 的务实目标；正式优势依赖差值区间和效用非劣，达不到时保留负结果。门禁通过不代表 Product 可发布。


## 16  风险、备选线与论文收口

*保留可推翻的结论*

| 风险 | 最小反证／处置 |
| --- | --- |
| 消歧证据根本不存在 | 完整档案不足案例单列；合理不确定，不惩罚不猜真值 |
| 元数据缺失／错误太多 | 实际与 oracle／shuffle 对照；保持原文回退，限制抽取迭代 |
| 假设遗漏、解释并非互斥 | 保留 open_set，不直接使用归一化概率；测覆盖和虚假共识 |
| 策略只是 EC² 或补槽检索重命名 | 同信息对照；贡献转为预测器、应用验证或失败边界 |
| 新增 metadata 又挤掉正文 | 元数据与材料共同预算；原文必要集合覆盖优先审计 |
| 系统正常任务退化 | 明确更正和无歧义对照必须保留；更少 token 不替代效用 |

### 第二研究问题：未被旧引用链引用的新反证

仅在主线完成 Go／Simplify／Stop 后再考虑。记录主体、属性、范围、时间的候选受影响关系；分开测“相关旧记忆是否被召回”和“召回后是否判断正确”。unknown 进入检查，不能当作无关证明。对自然语言范围不能宣称零漏修；先测候选减少率—漏修风险曲线，若近全量重算则停止优化。[L8,L9]

### 首篇论文最小交付

问题定义与可解性协议；一套实际 query-free 元数据；一个完整链、时态、补槽和通用主动取证的公平对照；至少一张未见来源主结果、一张成本曲线、一张预测器／策略消融；真实失败与数据许可。没有业务动作证据时，标题和结论限定查询证据选择。

### 本批立即交付，尚非实际执行

先完成 N0 的配置／来源清单和 N1 的只读最小入口设计，再组织 32 历史的 T0 审计。T1 未证明信号前，不开展完整多候选平台。源码实现、模型服务、真实模型实验和远端提交不属于本次文档交付，继续保持旧检查点状态。

> 成功不是“模块实现齐了”，而是知道：简单方案是否足够；廉价元数据是否真的有信息；在同一信息和成本下，新增方法是否仍然值得。

## 附录 B  外部文献与模板使用

*一手出处／不转移效果分数*

**[L1] Katsuno & Mendelzon — Updating vs. Revising a Knowledge Base。** Cambridge 章节摘要；用于区分世界变化与认识纠正。未据此宣称自然语言判定已解决。 [原始出处](https://www.cambridge.org/core/books/belief-revision/on-the-difference-between-updating-a-knowledge-base-and-revising-it/8ADFFF65FA776C21E8646D6F4D2434AB)

**[L2] Golovin, Krause & Ray — EC²。** Near-Optimal Bayesian Active Learning with Noisy Observations；arXiv:1010.3091v2。用于近邻与假设边界；本次未复现算法。 [原始出处](https://arxiv.org/abs/1010.3091v2)

**[L3] Javdani et al. — HEC。** Near Optimal Bayesian Active Learning for Decision Making；arXiv:1402.5886v1。涉及重叠决策区域。 [原始出处](https://arxiv.org/abs/1402.5886v1)

**[L4] Belief Memory: Agent Memory Under Partial Observability。** arXiv:2605.05583v2；核查摘要与 HTML 方法段，含历史保留及非联合后验说明。 [原始出处](https://arxiv.org/html/2605.05583v2)

**[L5] Zep: A Temporal Knowledge Graph Architecture for Agent Memory。** arXiv:2501.13956v1；时态知识关系近邻，不等于已接入原生系统。 [原始出处](https://arxiv.org/html/2501.13956v1)

**[L6] Beyond Dialogue Time: Temporal Semantic Memory for Personalized LLM Agents。** arXiv:2601.07468；语义时间与持续记忆近邻；实际使用版本仍需依赖冻结。 [原始出处](https://arxiv.org/abs/2601.07468)

**[L7] LongMemEval。** arXiv:2410.10813v2；五类长期记忆能力、500问题、时间感知查询扩展。本文未下载测试内容。 [原始出处](https://arxiv.org/abs/2410.10813v2)

**[L8] STALE。** arXiv:2605.06527v1；400冲突场景、1200查询。不是全部更正关系消歧的现成标签。 [原始出处](https://arxiv.org/abs/2605.06527v1)

**[L9] A Consistent Semantics of Self-Adjusting Computation。** arXiv:1106.0478v1；变化传播的理论近邻，不直接提供自然语言无漏修保证。 [原始出处](https://arxiv.org/abs/1106.0478v1)
