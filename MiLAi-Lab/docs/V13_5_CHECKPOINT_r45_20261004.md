r45 的三个失败分别是：

1. **更正的新值与所选来源不一致。** 单位由盎司改为克，原 ID 和新值正确，但字段支持只选择旧盎司来源。这是未解决的核心修订错误；引文身份正确和后续回答正确不能抵消。
2. **答复增加无依据事实。** 撤销、支持来源和历史均正确，答复却将用户的“结束了”说成“顺利结束”。保留撤销机制通过和完整任务失败两个判断。
3. **业务完成后提出不可用工具。** 实时查询与标签补办已成功，随后提出当前目录不允许的 `update_memory`，提供方以 UNKNOWN_TOOL 拒绝。业务真实效果保留，没有重复预订；协议与完整任务失败。

本轮普通答复、临时记忆、整条撤销和已有记录确认限定通过。剩余恢复、范围、遗忘与局部撤销故事未运行。
封存时共 16 次进程尝试；6 条记录、29 处引文身份与 current=latest 检查通过，语义错误仍单独保留。
